# 决策因子体系设计

## 1. 结论

因子核心池的证据长度现按 horizon 单独校验：除总画像天数外，1/5/20 日 Rank IC 与 1 日端点的非空观测数均须达到 `min_trade_dates`。正均值不能替代足够样本；缺失计数按 0 fail-closed。该门禁不改变因子公式或存储结构，也不补齐 release、输入快照、日期身份和样本外资格，详见[因子多周期有效观测数资格闸门](20261102-2152-factor-horizon-observation-gate.md)。

因子画像输入现以 `evidence_identity_v1` 绑定实际 factor release lineage、active trusted QFQ 内容快照、请求窗口、因子/代码版本和完整日期集合。温层 IC 只在逐文件 SHA-256 与 release registry 一致、计算前后内容不变、每个因子实际画像日期等于 QFQ 预期日期时写 `strategy_eligible`；完整文件清单进入审计 JSON。汇总不信任信封自述，而是从 `factor_profile` 重读日期集合并复核 hash/count/首末日，同时要求 eligibility 与 identity 各自只有一个 distinct 值。旧文本、混合身份、部分重算和任意子窗口都 fail-closed。为满足本轮“不改变存储结构”的约束，信封兼容承载于既有 `evidence_eligibility_reason VARCHAR(500)`；这是过渡性 provenance 载体，不是新增一等 schema。完整设计见[因子画像输入身份闸门](20261103-0313-factor-profile-evidence-identity.md)。

价值研究页每日初筛现有独立的 `value_research_diagnostics_v1` 诊断：20 日复权收益与 MA20 偏离、三年累计净利润/经营现金流覆盖和经营现金流 TTM。v7 报告另以 `value_research_shortlist_v2` 要求净利润 TTM>0（报表净利润，非扣非／归母；缺证据待核查），保留完整达标池，并用明确估值与质量门槛、确定性排序和研究容量上限产生最多 10 只、每行业最多 2 只的优先研究名单；容量递延不代表不合格。其为版本化研究门槛，不是新核心因子或收益认证；缺失证据不通过，基础准入、鲜度、原条件池、达标池与优先名单分层。完整公式、可信输入及缺失行为见[价格价值策略](../strategy/20260922-1314-price-value-margin-strategy.md#已实现初筛走势与盈利现金流研究诊断)。

`price_value_forward_observation_v1` 以冻结报告 cohort 做 5/20/60 交易日前向观察：补采名单从真实分析日之后开始，优先名单、达标池和原条件池成员等权冻结，后续个人过滤和财报修订不改变池。只消费可信前复权价格；缺失成员保留在分母并使结果不完整。毛收益、固定比例成本后观察值及相对原条件池差异仅用于检验规则增量，不能升级为因子资格、历史样本外回测或交易收益。

新增独立[双低一高研究选股策略](20261028-0157-quality-value-attention-strategy.md)：`quality_value_attention_v1` 使用25/25/15/10/10/15六维权重和四层漏斗，缺失/未来/过期证据阻断入选，保留逐股理由。证据包CLI之外，数据库只读CLI导出全股票池、可计算证据与缺口，不用代理因子补齐三年财务或人工判断，不把估值观察认证为历史可回测证据；不是通用多因子模板的别名。

研究合同补充（2026-10-28）：训练选参 `training_ic_v1` 的配置身份包含候选名称、版本和 `higher_is_better` 方向，避免方向不同的实验碰撞同一不可变窗口；请求权重仍按既定等权政策排除。既有训练产物不重写。日频回测 `daily_event_v3` 对持仓开市日缺行情采用 `reject_on_open_date_v1`，失败运行不保存成功绩效。估值 ORM 研究读取默认不认证 PIT、过滤晚间研究批次并保留来源；存在值不代表策略证据合格。

当前系统已经具备因子定义、运行、存储、横截面处理、IC/Rank IC、换手率和多因子评分底座，价量、风险、财务、估值、行业、情绪、宏观、政策、盈利预期、资金结构和拥挤度因子也已经有了首版落地能力。但多数上层因子仍是代理变量，关键短板从“没有代码”转为“数据源覆盖、时点正确性、样本外稳定性和组合调权验证不足”。

组合风险预算的波动率与跟踪误差以 active trusted `curated.prices_qfq` 温层发布为价格输入，读前、读后都核对发布校验值与 active 指针；不从控制面未复权日线推导收益。持仓与基准在同一次读取中取得，按交易日期对齐，每只标的用所属交易所日历检查开市日缺口；收益观测不足 60 个、目标日或任一必要日期缺价时不计算风险指标，需要该指标的组合草案直接阻断。默认风格预算只用当日 `momentum_20`、`volatility_20`、`liquidity_20` 完整观测的宽截面 z-score，约束绝对组合暴露；size 与 value 因估值时点缺口不纳入。各因子需单一成功运行、可信 QFQ 输入、样本至少 100、非零方差、三族证券池一致，且覆盖同日可信未复权股票价证券池至少 99%；每个拟持仓正权重标的也须有有限值。结果记录因子日期、版本、运行 ID、观测及参考证券数。缺证据即阻断，不以缺基准因子冒充主动暴露。行业、证券类型、现金约束和手数取整之后，再以最终目标权重复算风格、波动率与跟踪误差，最终超限时不发布草案。此口径只估算固定权重的历史价格收益风险，不包括未来公司行为、持仓变化和冲击成本。2026-11-16 只读核查中，`000300.SH` 的 QFQ 和控制面可信未复权价均仅到 2026-11-10，因此截至 2026-11-13 的跟踪误差预算被阻断；这是该日数据快照，不是永久禁用。

财务报表、财务指标、历史估值快照以及涨停、热股、龙虎榜等数据已经能够加工为可按历史时点回放的日频因子。宏观流动性、信用利差、政策事件、盈利预期和资金结构也已通过 `market.alternative_data_snapshot` 与因子服务形成首版代理变量，后续重点是补充真实来源、明确采集时间和信号生效时间，并验证它们适合作为仓位、风格和行业预算的调节层。

完整决策体系建议包含六个公司与市场层因子域：财务健康、基本面质量与成长、估值与安全边际、行业景气、市场情绪、价量与风险；同时补充五个上层因子域：宏观流动性、信用周期、政策与监管预期、盈利预期修正、资金结构与拥挤度。因子提供证据，不直接等同于买卖结论；最终结果仍需经过数据门槛、可交易性、组合约束和风险控制。

### 因子目录预注册

`backend/app/factors/registry.py` 的 `register_all_factor_definitions(db)` 把九个因子服务的 spec（价量、财务、估值、行业、情绪、宏观、政策、盈利预期、资金结构）以及 crowding 复合因子一次性预注册为 `factor.factor_definition` 目录条目，使因子工作台成为完整目录，而不依赖“跑过才有定义”。`ensure` 按 name+version 幂等 upsert，可重复调用。HTTP 侧暴露 `POST /factors/definitions/register-all` 触发注册并返回各类计数。

版本约定：

- 目录注册统一用 `v1` 作为规范定义版本。
- 价量与拥挤度因子在运行时按复权类型生成 `v1-{adjust_type}`（如 `v1-none`、`v1-qfq`、`v1-hfq`），因为同一因子名在不同复权口径下是不同序列；`factor_cross_section` 派生变换用 `v1-from-v1-{adjust_type}`。这些运行时实例与目录 `v1` 规范定义共存，各自带分类。
- `composite`（`decision_score`）依赖调用方传入的因子清单，属运行时动态组合，不在此预注册。

当前目录共 82 条规范定义，覆盖全部 11 个分类；运行时实例按实际计算产生。

## 3. 因子域设计

### 3.1 财务健康

该维度回答“公司会不会因资产负债表或现金流问题发生永久性损失”。首批候选：

| 因子 | 定义 | 方向 |
| --- | --- | --- |
| `debt_to_assets` | 总负债 / 总资产 | 越低越好 |
| `current_ratio` | 流动资产 / 流动负债 | 适中偏高较好 |
| `interest_coverage` | EBIT / 利息费用 | 越高越好 |
| `operating_cash_debt` | 经营现金流 / 有息负债 | 越高越好 |
| `accrual_ratio` | (净利润 - 经营现金流) / 平均总资产 | 越低越好 |

财务结构应在行业内比较。银行、保险、券商必须使用独立口径，不能套用普通工商企业规则。

### 3.2 基本面质量与成长

该维度回答“公司是否具有持续创造利润和现金流的能力”，包括：

- 盈利能力：ROE、ROA、ROIC、毛利率、营业利润率。
- 盈利质量：经营现金流 / 净利润、应收增长与营收增长之差、存货增长与营收增长之差。
- 成长能力：营收、净利润、经营现金流同比及三年复合增长率。
- 稳定与改善：利润率稳定性、ROE 稳定性、连续改善期数。

首版已经实现 `roe_ttm`、`roic_ttm`、`gross_margin_ttm`、`ocf_to_net_income_ttm`、`revenue_growth_yoy`、`net_profit_growth_yoy`、`roe_stability_3y` 以及三年复合增长、应收/存货异常和财务异常分等扩展项。

增长速度不能孤立使用。高增长同时伴随现金流恶化、应收或存货异常扩张时，应由盈利质量因子抵消得分。

### 3.3 估值与安全边际

价值研究页另有交易日晚间 PE/PB/披露 ROE 的全市场人工初筛。东方财富当前估值分页不可用时，只取供应商标注**同一交易日**的估值分析分页；两者均先落原始响应到 raw，再按沪深北逐所核对证券、可信未复权日线、供应商市场码、收盘价及有效 PE/PB 覆盖。供应商业绩报表的 `WEIGHTAVG_ROE` 保留公告和披露时间，换算为比率后用于逐股展示；缺失或报告期不同者单独复核，不用 `roe_ttm/v1` 单期代理补准入，晚间任务也不写该通用因子。研究估值行的 `_research_batch_id` 阻止通用因子与市值读取；供应商 PE 仍标周期待核。午夜生成覆盖及阻断报告，未知 ST、未核行业或来源冲突不猜测为正常。名单只用于人工复核，不能解释为 FCFE 绝对估值、安全边际、历史时点认证或历史全市场收益。原有单股 FCFE 假设历史模拟的期末净盈亏与该初筛没有收益归因关系。

新增[价格与价值匹配策略](../strategy/20260922-1314-price-value-margin-strategy.md)：以“没有坏股票，只有不合适的价格”为研究理念，由质量决定估值、误差和风险预算，由价格决定吸引力。只读 FCFE 研究及单股加现金的假设历史回测已实现，支持版本时点、次日开盘含费门槛、持有/退出、不自动加仓和现金保留；交易、净值与决策日志可追溯。预测仍是显式用户假设，当前 FCF 因子不自动等于 FCFE，历史模拟不等于历史时点认证或样本外验证。可信估值输入、公司行为会计、多股组合自动现金配置仍待实现。安全边际 `1 - P / V_low` 与下文 `intrinsic_value_gap` 的分母不同，不可混用；低估不能覆盖数据、准入和组合硬门槛。

“超出市场价值多少”更准确地应拆成两个问题：

1. 相对估值：市场价格相对同行是否便宜。
2. 绝对估值：市场价格相对保守内在价值是否有安全边际。

首版已实现参数较少、容易回测的相对估值：

| 因子 | 定义 | 说明 |
| --- | --- | --- |
| `earnings_yield` | TTM 净利润 / 总市值 | PE 的倒数，要求盈利为正 |
| `book_to_price` | 净资产 / 总市值 | 金融和重资产行业更有意义 |
| `sales_to_price` | TTM 营收 / 总市值 | 需结合利润率 |
| `fcf_yield` | 自由现金流 / 总市值 | 对资本开支口径敏感 |
| `ev_to_ebitda` | 企业价值 / TTM EBITDA | 便于跨资本结构比较 |
| `industry_valuation_gap` | 个股与行业估值分位之差 | 必须行业中性化 |

后续可实现 `intrinsic_value_gap = conservative_intrinsic_value / market_cap - 1`。内在价值模型需显式记录增长率、折现率、终值和情景假设。只有在压力情景下仍有明显折价时，才宜解释为安全边际。

估值域的共同前置依赖是可信的历史总股本、流通股本、总市值和按公告时点可得的 TTM 财务数据。

**估值历史序列已具备（2026-10-26）**。此前 `market.valuation_snapshot` 只有 3 个交易日，价值因子无法产出历史 IC。现在东财 `RPT_VALUEANALYSIS_DET` 的估值历史序列（2024-05-01 起）已发布为温层 Parquet 研究表 `research.valuation_history`，并新增 `value_earnings_yield` / `value_pb_mrq` 两个价值因子的逐日 IC 计算（`scripts/factors/compute_value_factor_ic.py`）。两个因子统一表达为「值越大 = 越便宜」，因此 IC 为正即「便宜的涨了」。

字段切换规则不能替代证据血缘：`close`、`pe_ttm`、`ps_ttm` 与市值类在供应商历史序列中看似按交易日/披露日切换，但整表全部行 `pit_verified=false`（今天采集的历史数据），没有当时快照与修订链，当前均仅为研究证据；**`pb_mrq` 还会按报告期末切换、最多前视 120 天**。因此价值因子的 profile 必须标为 `research_only`，不得进入核心池或表述为可交易证据。字段判定表与偏差方向登记见 `aiDoc/data/20261026-valuation-history-backfill.md` §4。

**`value_pe_ttm` 已退役（2026-10-26）**。`-PE_TTM` 在亏损股为正，样本 26.51% 为亏损，最便宜五分位 100% 是亏损股；该因子度量的是"亏得有多狠"而非"有多便宜"。修正后的证据发布到 `v2-valhist`，退役证据保留在 `v1-valhist` 供审计，定义标 `status='retired'`。

**因子池分级约束**（2026-10-26 起逐步加入，含后续证据资格检查）。秩 IC 只说明"单调相关"，不说明"极端分位可交易"。分级器现在同时要求：

| 闸门 | 判据 | 不通过的后果 |
|---|---|---|
| IC 闸门 | 三个 horizon 的秩 IC 均 ≥ 阈值 | 观察池 / 冻结池 |
| 覆盖率闸门 | `coverage_rate` ≥ 0.70（分母为**价格宇宙**，非因子自身非空集） | 冻结池 |
| **端点闸门** | 1 日多空（top−bottom 分位）价差**严格为正** | 观察池 / 冻结池 |
| **PIT 闸门** | `factor_definition.pit_status='point_in_time'` | `look_ahead` → 硬冻结；`unknown` → 不得进核心池 |
| **生命周期闸门** | `factor_definition.status='active'` | `retired` → 硬冻结 |
| **证据资格闸门** | 汇总画像均为 `evidence_eligibility='strategy_eligible'` | 研究限定证据不得进入核心池；该字段仍不等于完整策略认证 |

2026-10-26 旧口径历史结果为核心池从 4 个收敛到 **1 个**（`volume_stability_20@v2-qfq-2y`）：`max_drawdown_20` 因端点为负、`value_earnings_yield` 因端点为负且覆盖率 0.6957 低于 0.70、`value_pb_mrq` 因 PIT 前视而落榜。通用价值因子另按金融正确性排除银行/保险/券商等金融行业标的（其 PB/PE 口径与工业股不可横截面比较）。完整证据与判定见 `aiDoc/data/20261026-valuation-history-backfill.md` §6.2~§6.5。新增证据资格闸门后，[2026-10-27 资格审计](20261027-2122-strategy-readiness-audit.md)记录 `core=0`，v1 为 frozen、v2 为 observation；这是带日期的审计结果，不能代替后续实时核对。

### 3.4 行业景气

该维度回答“行业需求、价格、利润和资金关注是否改善”，分为：

- 市场层：行业指数相对强弱、成交额占比变化、行业宽度。
- 基本面层：行业营收增长、利润增长、ROE、毛利率中位数及趋势。
- 高频层：产品价格、产量、库存、开工率和订单等行业特有数据。

首版已实现 `industry_momentum_60`、`industry_breadth_20` 和 `industry_turnover_share_change_20`。后续补充 `industry_profit_growth`、`industry_roe_trend` 和高频景气指标时，应保留指标字典、单位、频率和发布日期，不强行统一成含义模糊的通用字段。

### 3.5 市场情绪

情绪因子用于描述风险偏好和拥挤程度，不是简单追逐热门股票：

- 市场级：涨跌停家数、炸板率、连板高度、上涨家数占比、成交额变化。
- 行业级：行业涨停占比、龙虎榜净流入、热度变化、成交拥挤度。
- 个股级：热度排名、龙虎榜净买入占成交额、异动频次、涨停强度。

首版已实现 `market_sentiment_score`、`limit_up_breadth`、`limit_up_failure_rate`、`hot_rank_change`、`dragon_tiger_net_buy_ratio`、`consecutive_limit_up_height`、`sentiment_temperature_percentile`、`overheat_reversal_signal` 和 `crowding_score`。

极端情绪可能代表短期动量，也可能代表拥挤反转。应保留原始子因子，让策略按持有期判断方向，不永久规定为“越高越好”。

### 3.6 价量与风险

当前已实现：

- 收益与趋势：`ret_1d`、`momentum_5`、`momentum_20`、`momentum_60`、`ma_gap_5`。
- 波动与回撤：`volatility_5`、`volatility_20`、`downside_volatility_20`、`max_drawdown_20`。
- 流动性与量能：`volume_chg_1d`、`turnover_rate`、`liquidity_20`、`volume_stability_20`。

它们适合描述市场行为、交易条件和风险状态，但不能替代公司价值判断。

### 3.7 宏观流动性与折现率

站在宏观交易员角度，A 股很多阶段不是由单家公司利润变化驱动，而是由“钱的价格”和“风险偏好”驱动。缺少宏观流动性因子时，模型容易把估值扩张误判为个股 alpha，也容易在流动性收缩期低估系统性杀估值风险。

首版已按状态变量落地，不直接做宏观预测：

| 因子 | 定义 | 用途 |
| --- | --- | --- |
| `rate_trend_10y` | 10 年国债收益率近 20/60 日变化 | 描述折现率压力 |
| `yield_curve_slope` | 10 年国债 - 1 年国债 | 描述增长与宽松预期 |
| `social_financing_impulse` | 社融增速或社融脉冲的变化 | 描述信用扩张方向 |
| `m1_m2_gap` | M1 同比 - M2 同比 | 描述实体活化与风险偏好 |
| `usd_cnh_trend` | USD/CNH 近 20/60 日变化 | 描述外部压力与汇率预期 |
| `commodity_inflation_proxy` | 南华/CRB/原油/铜等价格趋势 | 描述通胀与上游利润压力 |

宏观因子更适合用于调仓位、调风格和调行业权重，不宜直接替代个股打分。比如利率下行且信用扩张时，提高成长和高 beta 权重；利率上行且信用收缩时，提高现金流、低估值、低波动和高股息权重。

### 3.8 信用周期与资产负债表压力

财务健康因子看的是公司自身资产负债表，信用周期因子看的是全市场融资环境。缺少这个维度时，模型会低估地产链、城投链、周期品和小微企业融资压力对利润和估值的传导。

优先补充：

- 信用利差：AA/AAA 企业债利差、产业债/城投债利差。
- 资金价格：DR007、R007、票据转贴现利率。
- 信用可得性：社融、人民币贷款、企业中长期贷款、居民中长期贷款。
- 风险事件：违约、展期、评级下调、地产销售和土地成交压力。

信用周期因子主要用于风险门槛和行业权重。信用收缩期应降低高杠杆、长久期现金流、地产链和弱资质中小盘暴露；信用扩张早期则可提高顺周期和资产负债表修复方向权重。

### 3.9 盈利预期修正

当前基本面因子多数来自已经披露的财报，容易滞后。真正推动股价的往往是“未来盈利预期的变化”，不是静态 ROE 高低。缺少盈利预期修正因子时，模型会偏向后视镜，错过景气拐点，也容易买到已经开始下修但历史财报仍好看的公司。

建议因子：

| 因子 | 定义 | 方向 |
| --- | --- | --- |
| `earnings_revision_1m` | 一致预期 EPS/净利润近 1 月上修幅度 | 越高越好 |
| `earnings_revision_breadth` | 行业内上修公司占比 - 下修公司占比 | 越高越好 |
| `forecast_dispersion` | 分析师预测分歧度 | 低分歧更稳，高分歧更适合事件策略 |
| `guidance_surprise` | 业绩预告中枢相对市场预期差 | 越高越好 |
| `profit_warning_risk` | 业绩预告下修、亏损、变脸风险标记 | 越低越好 |

当前已经有一致预期修正、修正广度、预测分歧、业绩预告 surprise 和业绩预警风险的代理因子。若真实一致预期数据不足，可以继续用业绩预告、快报、公告关键词和历史季节性偏离做低配版代理，但必须在因子定义中标明置信度和来源。

### 3.10 资金结构与拥挤交易

情绪因子已经有热度和龙虎榜，但还缺“谁在买、用什么钱买、是否已经太拥挤”。这类因子对 A 股很关键，因为很多短中期行情来自资金结构变化，而不是基本面立即变化。

建议拆成四层：

- 外资与跨境资金：北向净买入、行业净买入、持股比例变化、汇率压力下的外资流出风险。
- 杠杆资金：融资余额变化、融资买入占成交额、融券余额变化。
- 产品资金：ETF 申赎、行业 ETF 份额变化、宽基 ETF 放量。
- 主动资金代理：基金重仓拥挤度、机构调研热度、龙虎榜席位结构、成交额分位。

首版已实现 `northbound_flow_ratio`、`margin_financing_change_20`、`etf_flow_industry_20`、`institutional_crowding_score`、`turnover_percentile_120`、`abnormal_volume_pressure` 和综合 `crowding_score`。拥挤不是永久负面：趋势早期的拥挤是确认，趋势末端的拥挤是风险，因此必须结合持有期、估值位置和情绪温度分位判断。

### 3.11 政策、监管与产业周期

A 股行业层面经常受政策定价影响。缺少政策与监管因子时，行业景气判断会过度依赖价格和财报，无法识别政策边际变化。

首版已先做事件型低频因子 `policy_event_score`，后续应扩展事件治理：

- 政策宽松/收紧：中央经济工作会议、政治局会议、国常会、央行和财政表态。
- 产业支持：新能源、半导体、AI、军工、医药、地产等行业政策强度。
- 监管压力：反垄断、集采、资本开支限制、环保限产、安全审查。
- 财政脉冲：专项债发行节奏、基建投资增速、地方财政压力。

这类因子不适合做高精度数值预测，适合做行业权重开关、风险提示和事件窗口标记。文档和数据库中应保留事件来源、发布时间、影响行业、方向、强度和有效期。

### 3.12 海外映射与全球定价锚

中国资产并不只由本土变量定价。美元、美国利率、全球商品、港股和中概股会通过风险偏好、汇率、外资和产业链传导到 A 股。

建议补充：

- 美债利率与实际利率：影响成长股久期和全球风险资产估值。
- 美元指数与 USD/CNH：影响外资流动和人民币资产风险偏好。
- 港股/中概映射：恒生科技、纳斯达克中国金龙指数对成长风格的外部定价。
- 商品链：原油、铜、金、煤、钢、锂、硅等对上游利润和通胀预期的传导。
- 全球风险偏好：VIX、信用利差、主要股指动量。

这些因子应主要用于市场状态识别和行业映射，不建议直接把海外资产涨跌简单映射为个股买卖信号。

## 4. 决策结构

不建议把所有因子无差别相加。建议采用“门槛 + 分层评分 + 风险预算”：

1. 数据门槛：财务发布日期、行情和行业归属可信，关键字段缺失则不评分。
2. 排除门槛：退市风险、重大财务异常、不可交易、流动性不足先过滤。
3. 公司评分：财务健康、质量成长、估值形成公司层得分。
4. 宏观状态：流动性、信用、政策和海外定价锚决定总仓位、风格倾斜和风险预算。
5. 环境评分：行业景气、盈利预期修正与市场情绪调整入场强度和持仓上限。
6. 交易评分：价量、资金结构、拥挤度、波动和流动性决定时机与执行成本。
7. 组合约束：应用单股、行业、风格、换手和容量约束形成目标权重。

可将以下权重作为研究起点，而非生产结论：

| 维度 | 初始权重 |
| --- | ---: |
| 财务健康 | 15% |
| 基本面质量与成长 | 25% |
| 估值与安全边际 | 25% |
| 行业景气 | 15% |
| 市场情绪 | 5% |
| 价量与风险 | 15% |

权重需通过滚动样本外回测验证，不能根据全样本最优结果反推。

在加入宏观和资金结构后，建议不要简单把总权重摊薄，而是把它们放在“调节层”：

| 调节层 | 默认用途 |
| --- | --- |
| 宏观流动性 | 调整总仓位、成长/价值、久期暴露 |
| 信用周期 | 调整顺周期、高杠杆、小盘和低资质暴露 |
| 政策与监管 | 调整行业权重和事件风险预算 |
| 盈利预期修正 | 调整基本面分数的前瞻性 |
| 资金结构与拥挤度 | 调整入场时机、止盈节奏和容量上限 |

## 5. 时点与防穿越规则

基本面因子最容易泄漏未来信息，必须遵守：

- 使用公告日或首次可得时间，不以报告期结束日作为可交易时间。
- 当前财务因子首版已按报告日期做保守过滤，但仍需升级到公告日/首次可得时间级别。
- 报告修订保留版本，只在修订公布后使用新值。
- TTM 只由当时已公开的季度数据计算。
- 财务数据至少从公告后下一交易日生效；发布时间未知时采用保守延迟。
- 行业分类和成分按历史时点取值，不用当前分类回填过去。
- 行业族因子已自 2026-11-11 起按 `market.security_industry_history` 的申万生效区间取时点标签；缺区间时显式回退当前标签，行业族与财务族把回退标的写入运行元数据 `fallback_symbols`，估值行业内分位与截面中性化路径只回退、不写元数据。政策族首版因子仍依赖现有标签口径，进入生产评分前必须显式标记为研究代理。
- 另类数据记录采集时间，收盘后数据只能用于下一交易日信号。
- 缺失值不填零，区分不适用、未披露、采集失败和历史不足。

## 6. 标准化与检验

每个因子进入策略前应完成：

- 在适用股票池内去极值、标准化或排名。
- 财务、估值和部分价量因子做行业中性化；规模敏感因子做市值中性化。
- 记录覆盖率、缺失率、分布、极值和横截面样本数。
- 计算 1/5/20 日 IC、Rank IC、分组收益、单调性和 Top 组换手；各持有期先取因子值与该期非空远期收益的共同证券集，再对因子值与远期收益使用平均秩并确定端点，相同值必须获得相同秩。
- 检查不同年份、市场状态、行业和市值区间的稳定性。
- 检查因子相关性，避免重复计算同一种风险暴露。
- 在交易成本、涨跌停、停牌和容量约束下做样本外回测。
- 1/5/20 日前瞻收益必须按证券所属交易所的目标开市日定义；目标日停牌或可信行情缺失时该证券标签缺失，不得顺延到下一条存在的行情，否则不同证券的 horizon 不可比。
- 周/月研究 bar 只能由同一复权口径的可信日线按交易所日历聚合：open/close 取周期首末实际交易 bar，high/low 取极值，volume/amount 保持原始单位求和；不完整周期默认剔除，缺失金额或成交量不得发布部分合计。该能力当前仅为内部研究函数，不是新的 `market` 事实表或公共行情 API。
- 端点 top/bottom 以名义分位边界的**因子值**为阈值，阈值处全部并列证券必须一并纳入，不得用证券代码切穿同值组来维持固定样本数；因此实际端点可能超过 20%，低离散度时两端可重叠。全体同值时端点价差记 0、单调性记未知。单调性分桶同样不得拆分同值组；top 集合换手使用前后集合的对称差异口径，避免并列组扩缩时漏报退出。
- 2026-11-02 前生成的既有 `factor_profile` 属旧端点口径；同日修复在线画像后，温层与价值 IC 脚本也已移除会切穿并列值的 `ntile(5)` 和非平均秩口径。旧画像与旧 JSON 均不自动改写，也不得与新口径日期混合聚合。恢复因子资格前必须对同一 `factor_version` 的完整评估窗口全量重算，并核验各日 `code_version` 一致。

单日 IC 只是诊断项。基本面因子应重点检验中期窗口，情绪因子重点检验短期窗口。

**端点检验是必检项（2026-10-26）**。上面的 IC 清单之外，还必须记录并检验**端点（top−bottom 分位）价差**：IC 为正只说明单调相关，极端分位仍可能亏钱。本项目已把「1 日端点价差严格为正」实现为因子池分级器的硬闸门，因此每个进入核心池的因子都必须有端点证据，而不是只有 IC。相关列：`factor.factor_profile.long_short_forward_return_1d / _5d / _20d`。

### 阶段 C：行业景气

- 补充行业财务聚合趋势。
- 再按重点行业接入价格、库存、产量等高频指标。

### 阶段 D：市场情绪

- 状态：涨停、热股、龙虎榜和过热代理因子首版已完成。
- 明确盘中、收盘后数据的信号生效时间。
- 分别评估短期动量和过热反转效应。

### 阶段 E：决策模型

- 状态：宏观流动性、信用利差、政策事件、盈利预期和资金结构代理因子首版已完成。

- 建立因子相关性与冗余诊断。
- 实现分层评分、门槛过滤和环境调权。

推荐顺序为 A -> B -> C -> D -> E。财务时点与历史市值是后续多个因子域的共同依赖，应优先完成。宏观和资金结构因子可以先以低频状态表落地，不必等待所有高频数据齐全。

## 9. 验收标准

### 9.1 2026-10-27 日级可用性快照

日线与因子闭环已推进到 2026-10-26，7 个生产价量因子目标日股票覆盖均超过 95%；财务、行业、情绪和部分资金流因子同步有值。该结论只表示**数据可用性**，不新增 IC 或收益证据。估值当日输入、宏观、政策、盈利预期与独立拥挤度输出仍为空，批任务按 `partial/empty` 留痕；完整行数、release 血缘与未闭合项见 [日线与因子数据闭环证据](../data/20261027-0118-daily-data-factor-closure.md)。

- 每个因子有经济含义、公式、方向、适用行业、输入字段和版本。
- 历史因子值可追溯到当时可得的数据及采集批次。
- 不使用未来公告、未来行业分类或当时尚不可得的信息。
- 因子运行可重跑且幂等，缺失策略明确。
- 报告包含覆盖率、IC/Rank IC、分组收益、换手和稳定性。
- 报告包含**端点（多空分位）价差**与分位单调性；进入核心池的因子其 1 日端点价差必须为正。
- 因子定义携带 `pit_status` 与 `status`；`look_ahead` 与 `retired` 的因子不得进入任何池，`unknown` 不得进入核心池。
- 决策结果可拆解到各维度贡献，组合约束后的调整原因有记录。
- 未通过样本外检验的因子不得默认进入生产评分。
- 单次回测工作台不得把未定义方向的因子静默解释为“高值优先”，也不得依据当前回测区间或无法证明早于测试期的 IC 自动定向；人工静态方向必须逐项确认并随结果快照回显。
- `validation_mode=none` 的人工方向单次回测只属于探索性证据，不得表述为训练窗自动选参、样本外验证或收益认证；自动定向只能通过训练窗与测试窗隔离的 rolling 选择政策完成。
- 工作台单次因子回测的 `preflight` 只读预演因子、调仓日期、公司行为、可信未复权行情及日频引擎，返回当前能否尝试运行与逐项原因；正式运行须重新校验，`evidence_qualified=false` 不因预演成功改变。基准比较只在可信基准行情与策略净值日期逐日对齐时计算，双方按共同首末窗口求收益；缺任一日期显示不可比较，不把短区间基准收益用于全期超额收益。
- 新回测运行使用消费切片摘要生成数据版本，基准输入按净值日期窗口保存首末价和逐日哈希，运行结束复核；基准缺日拒绝比较。旧运行没有固定基准快照，其比较结果明确标注为当前可信行情重算。`daily_event_v4` 对跌停或输入中显式不可卖 bar 阻断的零权重卖出逐个开市日重试，并保留有界执行事件；真实停牌日因可信层无 bar 仍按缺持仓行情 fail-closed，不能解释为已实现停牌重试。新目标覆盖旧目标。`a_share_cost_v2` 按股票/ETF 和成交日期拆分费用，2022-04-29 前不适用；费用仍是研究假设，券商实际费率与容量冲击未得到验证。绩效最大回撤从初始现金开始计算，历史绩效不自动改写。
