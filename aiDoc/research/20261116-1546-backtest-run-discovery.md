# 回测候选筛选与比较前口径检查

## 现状与决策

2026-11-16 研究库有 86 条回测运行，其中 82 条成功；`validation_mode` 分为 59 条 `rolling`、27 条 `none`，数据版本有 3 种。此前列表不显示验证模式、数据版本及费用模型，跨页选择比较对象需要进入每条详情核对。

- `GET /api/v1/backtests/runs` 增加可选的 `validation_mode`、`data_version` 精确筛选，均在数据库计数和分页前执行；既有策略、状态、起止日期条件保持原语义。筛选只读，不改变运行产物。
- 回测页展示策略原始标识、验证模式、数据版本和费用模型，并可按策略标识、状态、验证模式、数据版本与日期筛选。选择项跨页、跨筛选保留。旧请求不得覆盖新筛选结果。
- 比较预览将各项与首项的区间、数据版本是否一致明确标出；“同区间、同数据版本”仅是两项事实一致，不代表费用、参数、证券池、时点资格或样本外证据一致。`validation_mode=none` 显示为“探索性（未验证）”。

## T2 复核与验证

触发项是公共 API 查询参数与研究比较工作流。独立技术和产品复核均未发现 P0/P1；产品提出的策略标识可见性和验证模式措辞已修正。技术指出 JSON 筛选目前没有索引，在现有 86 条规模下风险低；运行数大幅增长时再评估索引，避免为当前只读筛选提前改 schema。变更可通过撤销查询参数和页面控件回退，无数据迁移。

隔离研究库 API 测试验证筛选先于分页；真实研究库只读核查得到 `rolling` + `warm-20261022-175052` 共 59 条，当前页 20 条且模式、版本均符合条件。前端测试覆盖筛选、分页、跨条件比较、无效日期与乱序响应。原回测金融计算和严格漂移比较未改动。
