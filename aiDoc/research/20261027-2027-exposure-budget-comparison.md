# 单因子研究策略仓位预算对照（2026-10-27）

## 结论

`evidence_gated` 保持单因子、top 20、20 交易日调仓和相同费用／组合约束。新增**可选** `invested_weight=0.8`：目标股票仓位为 80%，其余留作现金。它在两个已测试研究阶段都降低了回撤，也降低了收益；因此是明确的风险预算选择，不是收益或风险调整后效率已提升的证据。默认 `invested_weight=1` 保持原回测可复现。

新增参数后用默认值重跑 run #87，绩效字段与旧 run #79 **逐项一致**，证据见 `backend/outputs/evidence_gated_budget_default_check_20261027.json`。

## 触发与金融解释

run #79 最深回撤在 2026-03-23 达 −13.75%。当日 20/20 持仓同步下跌，持仓市值较前一交易日减少约 64,379 元，0 笔交易、0 佣金。单标原本约 5% 等权，调低 20% 的单标上限无法针对这次整体暴露风险；仓位预算直接限制整体股票风险。80% 只是预先明确的风险预算对照值，没有根据逐窗收益挑选。

## 资格与剩余门槛

- 两段都是事后研究，不是因子资格独立于测试窗的样本外验证。历史研究宇宙剔除了公司行为证券，退市样本覆盖不足；2026-05 之后的独立回测仍被公司行为事件会计缺口阻断。
- 80% 仓位没有改善 2025-11～2026-04 的夏普，降低收益是风险预算的成本。它不自动替代 100% 默认策略，不据此提升 `evidence_gated` 的策略资格。
- 2026-10-26 人工观察名单使用了额外的当前 ST、上市时长、流动性、波动和行业分散过滤，与上述回测合同不相同；回测收益不能归因于该名单。
- 后续要验证真实改进，应先补公司行为会计与退市价格，并让名单与回测共用同一可按历史时点重放的准入合同，再验证 2026-04 之后的独立窗口。

## T2 评审裁决

触发：改变研究策略的仓位预算口径。架构／规则视角有条件通过可选参数与同合同对照，要求默认结果可复现、文档记录局限；产品视角有条件通过风险方案展示，禁止把同段降回撤解释为收益优化；金融视角有条件通过总仓位风险预算，因为 run #79 的最大跌幅来自 20 只持仓同步下跌而非单股或费用。主代理采纳三方共同条件：只提供 opt-in 的 80% 方案，保留默认 100%，不调整因子、频率和名单阈值。研究入口无 P0；策略晋级仍被公司行为会计、退市样本与独立验证缺口阻断。回退方式是使用默认 `invested_weight=1`，其 run #87 已逐项复现 run #79。
