# 历史回测夏普与研究比较预览

## 现状与决策

2026-11-16 只读核查：独立研究库有 82 个成功运行，尚无已保存的 `strategy.backtest_performance`；其中 76 个有净值曲线，6 个缺净值。仅展示已保存绩效会使日常回测列表几乎全部处于“待计算”。

- 列表对当前页缺绩效运行批量读取研究库净值；详情从同一服务读取。复用现有 `BacktestPerformanceAnalyzer` 的首日相对初始资金、总体标准差、零无风险利率、252 日年化口径。GET 不保存绩效，不修改研究事实。
- `performance_status` 区分 `analyzed`（已保存）、`derived`（净值只读推导）、`missing_equity`、`invalid_equity`、`not_applicable`。缺净值或无效净值不显示 0，也不提供必然失败的完整绩效补算入口。波动为零时夏普为 `null`；推导指标记录当前服务端分析代码版本，已保存指标保留当时分析版本。
- 新增 `POST /api/v1/backtests/runs/compare-preview`，只读展示 2–20 个成功运行，按用户选择顺序返回，逐项标注区间、数据和运行代码版本、验证模式、费用合同、复权、收益、回撤、夏普、换手、费用及指标来源。缺净值项保留在预览中并明确缺值。前端选择跨页保留，可移除和清空。
- 回测页直接读取独立研究运行列表；运维概览失败不阻断回测和比较。列表读取失败保留上次结果或显示空态，并提供页面内重试。
- 原严格 `compare` 与 `drift` 维持既有语义，比较预览只作研究探索，不提供全体收益或夏普排名。不同窗口、数据版本和费用合同的结果不得直接认定为可比，更不构成样本外或实盘收益认证。

## 验证与边界

只读实库核查得到 76 项 `derived`、6 项 `missing_equity`、4 项非成功运行；76 项均有非空夏普。单元和跨库接口测试覆盖批量净值读取、推导/已保存来源、缺净值、零波动和版本；前端测试覆盖跨页选择、比较错误。旧运行不回填或改写，现有历史时点、公司行为与样本外资格限制仍适用。

## T2 评审结论

触发项为公共 API、关键研究工作流和金融指标读取语义。金融与技术独立复核未发现 P0/P1；产品复核发现的运维概览依赖与列表重试两项 P1 已修复并复查通过。风险等级为低：只读计算与新预览可通过回退服务和前端代码撤销，无 schema 或数据迁移。验证包括实际研究库只读结果、独立研究库 API 集成测试、完整 CI 与文档状态索引检查；实际页面走查受浏览器 URL 安全校验限制，前端交互由组件测试及构建验证。文档同步范围为本决策、roadmap、README、文档导航及状态索引。
