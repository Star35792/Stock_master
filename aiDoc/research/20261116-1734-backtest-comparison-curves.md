# 回测比较的同日净值与回撤曲线

## 决策

研究比较表仍覆盖所选 2–20 项。曲线区一次只展示首项基准和一项可切换的候选，避免多条线难以辨认及同时读取大量历史净值。比较预览先展示表格；曲线异步调用既有只读 `GET /api/v1/backtests/runs/{run_id}/equity`，读取失败不遮挡表格。默认候选是首个 `delta_status=available` 的运行；用户也可选择其他运行并查看不可绘制原因。

仅当后端已给候选 `delta_status=available`，且两条净值完整读取、交易日期严格递增并逐日相同、初始资金和每日总权益均为正且可供绘图时展示。单页 API 上限为 5000 行，前端继续分页，至多读取每条 10000 行；超出上限、分页缺失或日期不齐时整条曲线不画并给出原因，不展示截断曲线。切换候选、基准、所选运行或 URL 时，取消旧读取并用请求版本守卫结果。

归一化净值从运行初始资金等于 100 的期初点开始，首个交易日的变化计入；回撤峰值也从初始资金开始。净值已反映费用和滑点，不重复扣减。持久化金额与指标仍取后端 DECIMAL；前端 `Number` 仅用于绘图位置和近似标签，正式指标以比较表中的服务端结果为准。降采样保留分桶极值，避免长曲线遗漏孤立峰谷。基础合同对齐不能证明策略字段相同、收益归因、样本外认证或实盘资格。

## 评审与验证

触发 T2：关键研究比较工作流和金融展示口径变化。产品独立复核建议“基准 + 单个可切换候选”，先表后图，并在错误与竞态中保持表格可读；金融独立复核要求以初始资金计首日、完整净值与逐日日期核对、正值校验、费用不重复扣减。实现采纳这些边界。该功能不改 API、schema、研究库或持久化金融值；删除前端曲线区即可回退。

定向测试覆盖首日亏损、零波动、非正净值、日期重复或不齐、分页超过单页、超出绘图上限、长曲线极值保留、URL 恢复及候选切换旧响应。最终验证结果待本轮检查。实际页面和窄屏走查仍受浏览器 URL 安全校验阻断。
