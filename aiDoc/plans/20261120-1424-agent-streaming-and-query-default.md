# 智能体流式答复与默认查询

## 问题与决定

真实会话显示后端与DeepSeek已连接，但普通质量诊断被默认送入只生成计划的入口。
可选下钻/后续修复参数也被模型写成补问，页面再以固定缺参话术代替实际问题，用户看不到工具过程。
默认入口改为“查询与解释”，只读需求直接复用既有工具；需要采集、回测等写动作时显式选择“先规划”。
全局operations_overview/quality_issues不要求证券或日期；必要缺参仍补问，不猜证券、日期或资源ID。
规划聊天气泡展示实际问题/缺失字段，完整计划校验后展示目标及步骤。

## 流式合同

- 新增`POST /api/v1/agent/chat/stream`和`POST /api/v1/agent/plans/stream`，请求沿用`message/session_id`，响应`text/event-stream`；原JSON接口保留。
- `session`在需求持久化后立即返回身份；`phase/round/progress`展示当前阶段、技能加载与材料核查。
  `tool_start/tool_end`展示经过参数校验的实际调用及有界返回结果；工具失败保持失败。
- 查询通过DeepSeek `stream=true`转发`delta.content`为`text`。只转发公开答复，不传内部reasoning或工具参数碎片。
  工具参数完整组装后仍走原白名单/schema；`draft_reset`清除下一轮前的临时文字。
  规划结构化生成仍用完整JSON，只流阶段事件，不把未校验JSON作为计划正文。
- SSE事件带单调sequence；最终`done`只在会话CAS保存成功后携带权威会话。界面用它替换临时气泡。
  EOF、超时、异常、输出截断或缺少上游`[DONE]`均标未完成，不把草稿视为已完成答复。
- 单次流总时限360秒、4个并发槽、128项队列、总量2MiB；普通事件32KiB、最终会话512KiB。
  上游每轮90秒并沿用socket超时、1MiB输入流上限、最多4个工具和10000字符文本上限；流式输出额度4096 tokens。
  默认精简答复，按事实、缺失、推断与最多三项建议组织，不倾倒完整工具结果。
- 停止接收/断线后不启动后续工具或模型轮次；正在进行的同步调用可能先返回，停止接收不代表回滚。
  规划模型返回后再次检查取消，不新建后续草稿。已记录工具观察保留；末批未配对调用补服务器`interrupted/unverified`结果，不重放。
- 前端不自动重发POST；保存早期会话ID并提供载入原会话入口，代数隔离忽略旧请求。
  已保存需求清空输入；规划错误后GET恢复成功则清临时气泡，保留未完成提示，避免重复消息。

## 业务与事实边界

新增传输不改变SQLite会话事实、业务原服务事实、写关闭默认值或逐项确认。
完整市场覆盖率不在概览合同时必须说明未核验，问题数/成功任务数不能替代覆盖率。
公开过程只证明相应调用和观察发生，不认证研究目标或策略资格；不存在任意shell、SQL或脚本执行入口。

## 验收与回退

验证公开增量先于完成、工具参数片段组装、截断不成功、保存失败无done、中断工具历史配对及恢复不重放；
验证前端UTF-8/SSE分片、事件顺序、未完成草稿、卸载取消与规划错误恢复无双气泡。
浏览器以原质量诊断问题、必要缺参规划和停止接收/载入流程检查真实DeepSeek集成。
回退可恢复原JSON客户端及原默认方式，无schema迁移或业务数据复制。

本机普通启动另有既存DuckDB任务恢复索引错误；联调以`--lifespan off`手动模式启动，
不启动后台采集和调度，也不借本变更修复生产索引。完整写业务验收仍未完成。
