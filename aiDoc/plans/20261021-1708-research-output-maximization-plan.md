# 研究产出最大化行动计划

**制定时间**：2026-10-21
**触发原因**：用户询问「研究产出确实还没怎么产出，我需要怎样才可以得到最大化的收益」。

**项目边界**：本项目只用于**选股研究与持仓管理**，不连接券商、不做实盘自动化交易、不发送真实订单。系统产出止于「研究结论 + 选股名单 + 组合持仓方案 + 风险预算 + 持仓推演」，实际下单由人工在外部券商终端完成。本计划的所有"收益"均指研究结论与持仓建议的质量，不涉及自动交易能力建设。

## 结论先行

当前平台研究产出为空的根因不是「因子不够多」或「策略不够多」，而是**可信度链条断在两处**：

1. **历史数据在温层瘦身过程中被裁掉**：`market.daily_bar` 从 2016-07-25 ~ 2026-10-19（2483 交易日 / 1066 万行）退化为 2026-07-23 ~ 2026-10-21（59 交易日 / 32.5 万行）。任何需要 2 年历史的回测当前**无法复现**。
2. **报告数字与落盘证据不一致**：报告声称累计 +24.75% / 年化 12.20% / 夏普 0.556，落盘 `summary_*.json` 为 +7.83% / 年化 4.00% / 夏普 0.207。同一策略两组数字并存且无对应产出文件。

在这两点修复前，任何新增因子或策略都无法产生可信结论。因此**第一步不是加因子，是恢复数据与对账口径**。

## 明确不做（收益/成本比不划算）

- **实盘自动化交易（永久不在项目范围）**：本项目不连接券商；当前任何策略的收益数字也未经偏差修正。
- **新增因子族**：71 个因子的 IC 证据仍为 0。加因子前先出证据表。
- **复杂前端**：`frontend/src/pages` 仅 5 个页面，V6 写侧重跑仍是禁用占位，对收益无直接贡献。
- **分钟线 / Tick / 高频**：路线图已明确暂缓。

## 收益最大化路径（回答「怎样最大化收益」）

按对最终收益的影响排序：

1. **让数字变真**（P0）— 收益不是算出来的，是修出来的。回撤 -24.33% 而非报告的 -19.55%、年化 4.00% 而非 12.20%，差的不是策略，是口径。
2. **让因子可被评估**（P1）— 71 个因子一次都没被检验过。批量诊断跑一次，24 小时内就能知道哪些因子值得进组合。
3. **让偏差被扣除**（P2）— 涨跌停与 ST 缺失会系统性高估收益，尤其影响低价超跌类策略（这些恰恰是最容易涨跌停的票）。
4. **让约束进回测**（P3）— 行业/风格/换手约束不进回测，paper 链路的风险预算在研究阶段形同虚设。

### 策略层面的高价值方向

基于当前唯二可验证的研究：

- **低价超跌反弹**：落盘 2 年 +7.83% / 年化 4.00% / 夏普 0.207 / 回撤 -24.33% / 超额 +5.73%。绝对收益尚可但夏普极低，问题在回撤与换手（年换手 9.94 倍）。**降换手、提胜率**比加信号更有效。
- **2026-10-16 选股池次日 -1.30%**：该逻辑已被短期证伪，不应作为主线。
- **已具备但未用上的组合能力**：84 个 spec 因子、60 个 API、组合风险预算四约束（行业/风格/跟踪误差/波动率）全部就绪，但从未在真实回测中组合过。**「5-10 个强因子等权/IC 加权 + 行业中性 + 低换手」是当前投入产出比最高的研究配置。**

### 预期收益区间

- **短期（1-2 周）**：P0 全部完成后，2 年回测可复现，数字可信。收益预期 = 真实的 +4% 年化，而非报告的 +12%。
- **中期（1-2 月）**：P1 完成后得到第一张 71 因子 IC 表 + 因子池分级名单。此时才具备「选因子」的决策依据。
- **长期（3-6 月）**：P2+P3 完成后，回测-归因-组合-风控-持仓推演全线打通，具备稳定选股与持仓建议的产出能力。届时可谈策略收益，但无法事前承诺数值。

## 风险提示

- 上述路径**不保证正收益**。P1 的 IC 表可能显示大部分因子无效——这本身就是高价值结论，能避免在无效因子上继续投入。
- 涨跌幅/ST/涨跌停数据回填受外部数据源可得性限制，可能只能做到部分覆盖。
- 收益数字从「报告 +12.2% 年化」修正到「落盘 +4.0% 年化」是**下调**而非上调，目的是让决策基于真实值。
