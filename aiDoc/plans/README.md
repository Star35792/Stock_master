# 计划与路线 Reference

## 当前阶段

- 当前整体处于 V6 最小运维工作台阶段。
- V4 已有因子选股回测创建入口、回测结果查询和绩效归因入口。
- V5 组合、风控、模拟盘已有服务与落库闭环，但缺稳定外部操作 API 和前端工作流。
- V6 已有最小运维概览工作台，但详情、告警和细粒度重跑仍未完成。
- V7 尚未开始；只在 V4、V5、V6 阶段门完成后评估真实账户只读同步和受控交易边界，默认不做自动实盘交易。

## 近期优先级

1. V4 单策略研究合同和可复现回测切片：版本追溯、重复运行一致性和最小回归测试。
2. V6 运维工作台深化：详情页、告警、失败定位、细粒度重跑入口。
3. V5 外部操作 API：组合、风控、模拟盘的公共 schema、稳定路由、前端工作流、人工确认和审计流程。
4. V7 实盘只读与受控交易：只读同步、对账、幂等状态机、人工确认、应急开关和审计日志；前置阶段门未满足时不启动。

## 下一步切片边界

当前实施决定是先完成 V4 单策略、单参数集、单次回测的研究合同闭环。批量运行、跨运行比较、样本外验证、V5 交易 API、真实账户接入和自动交易均列为后续任务，不因本次测试通过而提前纳入。

## 计划文档同步规则

- 改阶段状态、优先级或交付范围时，更新 `aiDoc/plans/roadmap.md`。
- 改项目入口表达或 API 面时，更新 `README.md`。
- 改文档导航、阅读顺序或当前状态摘要时，更新 `aiDoc/README.md`。
- 临时任务计划不要写入正式文档；只在任务执行中用 todo/plan 管理。

## 决策治理

- 涉及产品、架构或金融语义的重大决策，以及 AI 代办的提交前检查，按 [决策与提交评审协议](decision-review-protocol.md) 执行。
- 评审过程保留在当前任务、提交说明或 PR 中；只有长期稳定的结论才同步到对应 `aiDoc`，不要为每次评审新建文档。
