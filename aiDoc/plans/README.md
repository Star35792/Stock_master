# 计划与路线 Reference

## 当前阶段

- 当前整体处于 V6.1 只读运维工作台收口后、转入 V5 公共操作闭环的阶段。
- V4 已完成单次回测研究合同闭环，并交付批量运行、验证区间合同、交易日窗口生成、基准/跨运行比较和同合同回归漂移诊断；训练、选参及训练产物血缘尚未形成自动编排闭环。
- V5.1 已交付组合手工模拟草案；V5.2 已交付只读风险前数据核对、paper 账户净值历史、服务端 ADV 和绑定不可变输入的正式风险评估；V5.3 已开放五分钟有效的人工确认、一次性原子消费和幂等模拟执行批次。当前固定 local single-user、paper-only、确定性 full-fill 和全批原子语义；不会连接真实券商。
- V6.1 已有最小运维概览工作台、告警候选摘要、按分类限量的失败定位摘要、单项失败详情、只读重跑计划和前端执行前准备态；细粒度重跑执行属于后续写侧任务，需先完成权限、审计、幂等和人工确认设计。
- V7 尚未开始；只在 V4、V5、V6 阶段门完成后评估真实账户只读同步和受控交易边界，默认不做自动实盘交易。

## 近期优先级

1. V5 外部操作 API：组合、风控、模拟盘的公共 schema、稳定路由、前端工作流、人工确认和审计流程。
2. V6 写侧运维动作设计：细粒度重跑执行入口仅在权限、审计、幂等和人工确认边界明确后启动。
3. V4 后续研究编排：训练选参产物留痕、窗口与运行不可变绑定、参数敏感性和回归金样本。
4. V7 实盘只读与受控交易：只读同步、对账、幂等状态机、人工确认、应急开关和审计日志；前置阶段门未满足时不启动。

## 下一步切片边界

V4 单次回测研究合同及其支撑 API 已交付。滚动窗口按指定交易所的 `market.trading_calendar` 开市日计数；样本外/滚动字段目前记录外部训练与选参区间，不代表平台已自动完成训练或选参。回归漂移只允许比较除代码版本外研究合同一致、测试区间一致且数据版本一致的成功运行。

详细执行计划：[V4 单策略研究合同与可复现回测计划](v4-research-contract-plan.md)

## 计划文档同步规则

- 改阶段状态、优先级或交付范围时，更新 `aiDoc/plans/roadmap.md`。
- 改项目入口表达或 API 面时，更新 `README.md`。
- 改文档导航、阅读顺序或当前状态摘要时，更新 `aiDoc/README.md`。
- 临时任务计划不要写入正式文档；只在任务执行中用 todo/plan 管理。

## 决策治理

- 涉及产品、架构或金融语义的重大决策，以及 AI 代办的提交前检查，按 [决策与提交评审协议](decision-review-protocol.md) 执行。
- 评审过程保留在当前任务、提交说明或 PR 中；只有长期稳定的结论才同步到对应 `aiDoc`，不要为每次评审新建文档。
