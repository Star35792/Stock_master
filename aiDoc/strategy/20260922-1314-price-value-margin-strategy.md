# 价格与价值匹配策略：没有坏股票，只有不合适的价格

> 状态：只读估值研究与单股加现金的假设历史回测已实现，完整策略执行待实现。本文是本策略定义的唯一真源；历史模拟使用手工假设与当前可信行情版本，不构成历史时点认证、样本外收益验证或交易资格。
> 定位：在现有多因子研究体系中增加绝对估值与风险补偿视角，作为候选子策略，不替代其他策略和统一风控。

## 1. 投资理念与适用边界

用户理念：“没有坏股票，只有不合适的价格。”

金融实现定义：**在数据可信、价值可估、符合准入且风险可承受的证券范围内，公司质量决定估值、估计误差和风险预算，价格决定投资吸引力。** 优质公司买得过贵也可能回报不佳；经营普通或暂遇困难的公司，在保守价值可验证且价格充分补偿风险时，可以成为研究候选。

不因“优质”无条件买入，不因低质量标签永久排除可估值的普通企业；也不假设每只股票都存在可接受的正买价。股权可能因永久性损失而归零，价格低、跌幅大、低 PE/PB 或历史高价都不能单独证明便宜。

金融专家视角分工：企业分析判断现金流和持续经营能力，估值分析形成情景区间，组合管理决定风险预算，执行风控判断能否成交。任何单一估值分数不能覆盖这些职责。

## 2. 先准入，再定价

沿用项目的数据质量、证券生命周期、ST/退市、停牌、流动性和组合门槛。研究可覆盖观察标的，但交易候选必须满足既有 universe 规则；不以折价覆盖硬门槛。

| 情况 | 研究处理 |
| --- | --- |
| 数据完整、业务可解释、价值可估 | 进入情景估值 |
| 经营走弱但财务可信、仍可可靠估值 | 下修价值、扩大不确定性范围、提高所需折价并压低仓位上限 |
| 财务造假或关键数据无法信赖、剩余股权难以估计 | 阻断买入研究结论，记录原因，不输出伪精确买价 |
| 数据缺失、过期、模型不适用 | 标记“无法评估”，不得当成零风险或低估 |
| 停牌、退市限制、流动性或组合预算不满足 | 标记相应限制；即使估值便宜也不产生可执行买单 |

亏损企业、困境重组不使用普通盈利倍数硬套价格；首版不覆盖不能可靠估值的困境股。恢复资格必须有新的可追溯证据。

## 3. 估值方法与情景

每次估值输出悲观、基准、乐观三种情景的**当期每股权益价值** `V_low <= V_base <= V_high`，并记录估值日期、适用行业、模型、输入、关键假设和有效期。`V_low` 是保守情景估计，不是保证底价；无法形成可信保守价值时不计算买入价。

| 企业类型 | 主要估值视角 | 必须核查 |
| --- | --- | --- |
| 现金流稳定的非金融企业 | FCFF/FCFE 折现，盈利倍数交叉核验 | 维持性资本支出、营运资本、持续盈利能力 |
| 周期企业 | 正常化盈利与现金流、资产价值交叉核验 | 不用景气顶点利润推导“低 PE” |
| 银行、保险、券商 | 各自适用的股利、剩余收益或权益模型 | 资本约束、资产质量和行业专属风险，不套工商企业债务率门槛 |
| 成长或暂时亏损企业 | 可解释的盈利路径、现金消耗及稀释情景 | 未形成可信路径时保持观察，不以远期收入直接承诺价值 |

FCFF 使用与之匹配的 WACC，并从企业价值扣除净债务、少数股东及其他优先权益、加入适用的非经营资产后得到普通股权益价值；FCFE 使用权益资本成本且不重复扣债。最终按同一时点、同一权益口径的稀释股数换算每股价值。

折现率、增长率、预测期、终值、债务与现金调整、股份稀释都需版本化；永续增长模型要求折现率大于长期增长率，币种与名义/实际口径匹配。相对估值只做交叉核验，同行整体高估时不能推出绝对便宜。

## 4. 合适价格的定义

对 `V_low > 0`、当期未复权报价 `P > 0`，定义：

```text
gross_margin = 1 - P / V_low
P_all_in = P + 该笔拟买入数量对应的每股买入费用与滑点
cost_adjusted_margin = 1 - P_all_in / V_low
buy_cost_ceiling = V_low * (1 - required_margin)
买入价格条件：P_all_in <= buy_cost_ceiling
```

`required_margin` 满足 `0 < required_margin < 1`，在训练/研究阶段预先确定并锁定版本，不使用未来收益反推当期参数。估值误差、周期性、治理和流动性风险上升时，重新估值并收紧安全边际及风险预算；不可估值风险不得通过任意提高折价“解决”。

报价、费用、每股价值必须具有一致币种、当期股本与公司行为口径；核心金额和比率使用 Decimal/DECIMAL。最低佣金意味着买入上限依赖拟买数量，不能把 `buy_cost_ceiling` 直接当作可挂单报价。

原研究框架的 `intrinsic_value_gap = V_low / P - 1` 是相对报价的价值差，不等于上述以价值为分母的安全边际。界面和报告必须区分两者。

另评估预设持有期内的净预期总回报：按情景模拟未来卖出价、期间现金分红、费用、税费和资金占用，按现金流时点计算年化回报，与同期限回报门槛比较。当期折现价值不是未来卖出价，不能直接用 `V_base/P-1` 宣称年化收益；当期 DCF 已包含的分红不能再加一次到内在价值。

### 数值示例（纯演示，不是推荐参数）

假设一家公司当期三情景价值为 10/13/16 元，所需安全边际 30%，含买入成本上限为 7 元：

| 含费买入价 | 成本后安全边际 | 研究结论 |
| --- | --- | --- |
| 6.50 元 | 35% | 达到价格条件；其他准入、收益与预算门槛通过后才是候选 |
| 9 元 | 10% | 价格不合适，等待；不因公司好而追价 |
| 5 元，但保守价值已下修至 6 元 | 约 16.67% | 新成本上限仅 4.20 元，不能因跌得更多自动加仓 |
| 任何低价，但关键财务不可信 | 不可计算 | 阻断，不能以便宜覆盖数据风险 |

## 5. 决策与持仓管理

顺序为：可信数据 → 准入 → 情景估值 → 价格与净回报条件 → 风险预算 → 组合/执行风控。

- 未持仓：信息不足时输出“无法评估”；价格未到输出“等待价格”；条件满足输出“买入研究候选”；预算不足输出“组合受限”。可同时保留多个原因。
- 已持仓：买入条件不再满足不等于立即清仓。使用预先记录的持有/退出条件，避免同一阈值附近反复买卖。
- 当期报价达到或高于 `V_base`：触发估值与剩余回报复核，可提出减仓研究建议，不代表必然卖出或确定高估。
- 论点失效、价值永久下修或风险预算超限：优先风险复核，按既有规则提出降仓/退出；无法成交时记录待处理状态，不虚构卖出。
- 超过预设持有期限、复核期限，或出现财报、再融资、重大治理事件：重新估值；过期估值停止支持新增买入，存量持仓进入复核。
- 加仓必须重新满足估值、价格和预算条件，不因价格下跌或浮亏自动摊平。单股、行业、风格、流动性、现金和组合回撤约束优先于估值排序。
- 无合格候选时持有现金；候选不足时保留未分配预算，不为了凑满 Top N 或满仓而降低要求。

完整研究输出至少包含：symbol、估值时点、数据可得时点、情景价值、报价及时间、拟买数量与费用假设、买入成本上限、两种安全边际、持有期及净回报情景、估值假设、风险、失效条件、下一次复核时间、限制原因和数据/模型/参数版本。当前已发布的只读子集见下节，持有期净回报和组合预算仍未评估。

## 6. 项目落地与验收

页面 `/price-value` 按“找待研究的股票 → 评估一只股票 → 查看假设历史表现”三个任务入口组织，默认展示全市场初筛。数据阻断时先解释原因；若报告完整但 0 只通过门槛，默认展示带逐股缺口的全市场原始指标，PE/PB/ROE 条件仅过滤当前页面，不产生候选名单或交易信号。0 只通过不代表市场没有低估机会。任务执行失败或尚无报告时不显示原始指标表；完整原因与报告仍可展开或导出。收益记录在独立区域展示，与初筛名单没有收益归因关系。切换入口保留本页尚未提交的表单及已有研究结果，复制手工 FCFE 假设到回测时保留原始可得时间。预填安全边际、折现率、费用等只是待核对的研究示例，不是系统推荐值。

### 已实现：只读 FCFE 情景研究

- 页面：`/price-value`，菜单“估值研究”；接口：`POST /api/v1/strategy-research/price-value/evaluate`，不写数据库、不生成权重或订单。页面可导出本次研究 JSON；修改参数立即使旧结果失效。
- 输入：证券与报价日期、含时区的估值/假设首次可得/有效期时间、假设版本及依据、普通股稀释股数、三情景逐年 FCFE 总额和明确的 N+1 年终值现金流、权益资本成本、永续增长率、安全边际、拟买股数及显式费用参数。金额单位为人民币元、股数单位为股，不能将万元/万股混入；比例为小数。只支持稳定现金流非金融企业和 1–10 年正 FCFE 预测。
- 计算：`V = (Σ FCFE_t/(1+ke)^t + FCFE_(N+1)/(ke-g)/(1+ke)^N) / diluted_shares`，固定年末折现，不再扣债。每股价值使用 Decimal，以 `ROUND_HALF_UP` 保留 10 位小数后参与价格判断，舍入后非正值拒绝；情景次序错误拒绝，不自动排序。显式终值预测需要包含与增长、再投资及融资结构一致的假设。
- 费用：复用现有 A 股费用内核，所有费用参数由研究请求显式提供，买入不计卖出印花税。`buy_cost_ceiling` 是每股全部买入成本上限；`max_buy_quote` 是在数量、最低佣金和滑点约束下，以 0.01 元价格档位验证得到的最高原始报价，零表示不存在满足条件的正报价。费用仅为研究假设，不代表真实券商收费或订单合法性。
- 行情：只读精确日期的 `market.daily_bar` 未复权报价，要求可信且非可疑、完整来源与更新时间；当前版本晚于估值时点时阻断。本研究保守地在北京时间 16:00 后使用当日日线，并限制报价距估值时点不超过 7 个自然日。这些检查不能替代真正的历史可得时间认证。
- 准入：证券、行业、上市日期、ST 状态缺失，金融行业、非活跃/退市证券、停牌、非正成交额/量、涨停报价、过期或未来假设、论点失效等均阻断，不返回价格指标。当前证券主数据只用于保守筛查，不认证历史 universe。持仓依据失效或报价达到基准价值时提示复核，不自动清仓。
- 返回：三情景价值、两种安全边际、价格条件、费用、行情和证券快照、假设回显、阻断/复核原因、模型/代码版本、输入合同哈希和评估时间。状态为 `blocked / price_condition_met / wait_for_price / review_required`。哈希绑定实际输入而非签署完整输出，不是不可变存储证明。
- 固定边界：`research_only=true`、`pit_verified=false`、`execution_eligible=false`、`new_allocation=none`，调用方不能覆盖。FCFE 与股本为用户研究假设，不能自动将现有 CFO−CapEx 因子解释为 FCFE。没有净预期收益、组合预算和完整时点验证时，价格条件满足不等于可以买入。

验证覆盖独立计算、服务门禁、隔离 DuckDB 的真实 repository/API 查询及不写入检查；浏览器验证达标、等待、缺行情阻断和修改后结果失效。上述验证证明计算与交互行为，不证明策略收益。

### 已实现：单股加现金的假设历史回测

- 入口：同一研究页的“假设历史模拟”；`POST /api/v1/strategy-research/price-value/backtests` 创建研究，`GET /api/v1/strategy-research/price-value/backtests/{run_id}` 恢复完整报告。复用现有 `strategy.backtest_run / backtest_trade / backtest_equity / backtest_position`，不新增表或迁移；写入研究记录不改变 paper 账户，不产生真实订单。只读估值接口仍不写数据库。
- 请求：单只沪深主板 CNY 普通股、起止日期（最多 1096 自然日且结束日北京时间 16:00 已过）、初始现金、开仓预算比例、安全边际、显式买卖费用、以前一交易日成交量为基准的最大参与率（至多 10%）、一个或多个 FCFE 假设版本。每版须含唯一版本号和首次可得时间、估值时间、有效期、来源说明、稀释股数、三情景及论点失效标记；要求 `valuation_at <= available_at <= valid_until`。网页复制研究表单时保留原始时间，不能将当前假设自动回填为历史。
- 时点：北京时间 16:00 用最新已声明可得版本评价当日收盘价；新版到期不回退到旧版。交易在下一开市日 09:30 使用开盘价执行。若开盘前出现新版或买入依据已过期，撤销旧买入信号，等当日收盘重新评价。手工声明可得时间不代表已核验历史预测；估值在有效期内固定，不自动滚动折现。
- 开仓：仅空仓生成买入信号，100 股整手；开盘按真实数量、最低佣金、税费、滑点、资金预算和前一日成交量容量重算，确认每股全部成本不高于 `V_low*(1-required_margin)` 才成交。剩余预算持现金，不借款、不自动加仓，也不因为价格离开买入区间立即清仓。开盘不使用当日最终成交量或最高/最低价决定成交数量。
- 退出：本模拟为可复现研究，明确选择“收盘达到 `V_base` 或最新已知论点失效 → 次日卖出”的实验政策；它不同于第 5 节一般策略的人工复核建议。已知论点失效不随价格估值有效期结束而解除。退出因停牌、跌停、容量或费用不足未成交时保留意图；部分卖出后继续处理余量。普通估值到期停止新买入、已持仓记录复核。期末持仓按末日收盘估值，不虚构平仓；现金不计利息。
- 市场输入：只消费交易日历、证券、未复权可信且非可疑日线及公司行为的 `market` 层。交易日行情须完整，非正/非法 OHLC、缺量额、非停牌却零量或零额、历史 ST/状态未知、缺有效涨跌停价、生命周期/行业不满足均拒绝整段运行。停牌可保留零量行情以记录无法成交。公司行为区间在事件会计实现前一律拒绝。涨停不买、跌停不卖，滑点后成交价须在当日限价内。前日量只是容量代理，不保证真实开盘深度或成交。
- 留痕：保存完整请求、当前市场输入快照、模型与代码版本、执行/退出/精度政策、合同及数据哈希；独立数据库会话比较运行前后输入，变更时失败。该检查只证明本次计算的输入一致性，不认证历史修订可得时点。内部执行使用 80 位 Decimal 上下文，估值统一舍入至 10 位；费用复用原内核。标准研究表保留其既有定点精度，完整报告 JSON 保留计算输出精度。
- 输出：区间净收益、最大回撤、期末现金与净值、成交、每日权益与持仓、逐日信号/未成交/复核原因和限制说明，可导出 JSON。固定 `research_only=true / pit_verified=false / execution_eligible=false / validation_mode=none`。价格回测不补充净预期收益或组合预算验证；当前主数据会产生幸存者限制，当前修订行情也不能声称无未来信息偏差。

验证覆盖最低佣金与整手、费用后阈值、跳空取消买入、未来/夜间/过期版本、无加仓持有、论点失效与基准退出、停牌/涨跌停/容量及退出重试、期末持仓、实际现金守恒、零费用不被默认值覆盖、数据库持久化/查询与失败不写入。

交付依赖说明：研究结果复用现有表；所依赖的 raw/market 日线限价和状态字段随本切片交付，并由当前 DuckDB 初始化兼容桥幂等补列，细节见[日线契约](../data/daily-bar-contract.md)与[存储说明](../modules/schema-plan.md)。升级保留已有行情值，对缺失限价和特殊处理状态不猜测或自动补历史；只在隔离数据库验证升级与重入，不直接修改用户数据库。

### 已实现：全市场相对估值人工初筛

- 每个上海交易日 21:00 后，只有当日 SH/SZ/BJ 日历完整且自动日线同步成功，才采集东方财富 PE/PB/收盘价。当前 clist 首页不可用时，退回供应商标注**同一交易日**的估值分析分页，仍须以可信日线核价；后续分页失败不得中途切换。逐页写入 `raw.import_batch` 与 `raw.vendor_snapshot`，留存 UTC 采集时间、目标交易日、响应哈希和批次。无日期参数的 f9 周期未核，日期接口虽有 `PE_TTM` 字段，两者在本页均只称供应商 PE，不发布至通用 `pe_ttm`。
- 同日晚间从东方财富最近报告期向前查找两个有披露值的业绩报表期，保留各期逐股值并读取 `WEIGHTAVG_ROE`，保留空期响应、报告期、公告日、披露时刻、抓取时间和原始页哈希；公告晚于目标日或披露晚于抓取时刻的值不进入当晚研究观察。`WEIGHTAVG_ROE` 是供应商披露的加权平均 ROE；缺失或较旧报告期留待单独复核，不用单期净利/期末权益代理补准入。
- 只有证券与 CNY 主数据一致、同日可信未复权日线存在、供应商收盘价与可信价相差不超过 0.01 元的观察值才发布到 `market.valuation_snapshot`。沪深北各自核对证券、市场码、可信日线、收盘匹配、有效 PE/PB 和同一主报告期披露 ROE 覆盖（每所至少 80%）；不足时保留 raw 和失败原因，不发布。研究观察值带 `_research_batch_id`，通用因子与市值读取默认排除，晚间任务不生成通用 ROE 因子；批次及任务成功标记按门禁提交。覆盖旧同日快照前将旧内容另存 raw 供审计。
- 午夜从当日验证的 `market` 研究观察值生成逐股 PE/PB/披露 ROE 名单、原因、来源与快照哈希；输入准备、目标日期或来源批次不一致即阻断。金融行业、停牌、上市日期/行业/ST 未核验、行业来源冲突、与主报告期不同的 ROE 和无效倍数留在全市场报告中单独复核；若较旧期是最新满足覆盖的公共期，已披露更新期的证券同时显示两期 ROE 和来源供人工核查。供应商行业仅作提示，不代替已核证券行业；网页按沪深北展示有效指标与同步状态，阈值只比较选定的主报告期且不设默认便宜标准；不输出安全边际、组合权重、订单或自动买入。结果固定 `research_only=true / pit_verified=false / execution_eligible=false`。
- 该名单是当晚观察值，不可倒填供应商历史时点，不能用来计算“历史全市场策略收益”。同页保留用户提供 FCFE 假设后的单股现金回测；净盈亏为期末权益减初始现金，含未平仓市值，仅是假设结果。模拟账户缺可核验投入和资金流基线时不声称累计利润。
- 东方财富估值分析日期接口可补采指定过去交易日的供应商原始估值；目前只存独立 raw 批次，记录真实抓取时刻和供应商标注交易日。历史 raw 未经首次可得时间、修订版本和下游隔离认证，不进入本页初筛、通用估值因子或回测，故补采完成也不会自动产生昨日名单或历史利润。

### 待实现：可信估值输入与完整策略执行

当前已有财务和相对估值因子首版；`backend/app/strategies/templates.py` 的横截面模板仍为排名选取和等权分配，不能代表本策略的绝对价格门槛或现金保留机制。绝对估值情景、可靠历史股本、公告/修订时点的完整验证仍需补齐。

后续按以下顺序实现，服从现有前置硬门槛，不将本次文档完成视为上线：

1. 定义可追溯的估值输入与情景产物：外部资料走 `raw -> market`，研究只消费可信层。保留公告、首次可得、采集、修订及模型生成时间；历史研究使用当时可得版本，回填时间不能伪装为历史可得时间。
2. 先覆盖可解释现金流的有限行业范围，完成估值计算及只读解释。每次估值绑定数据、代码、模型和参数版本，缺失/过期/不适用时明确阻断。
3. 再实现支持持现金的独立策略决策，保留现有分层：估值证据进入研究，组合服务决定目标权重，风控与执行决定是否成交；API 不承担估值计算。
4. 回测验证公告时点、历史行业与成分、退市样本、股本稀释、分红复权、费用滑点、容量及不可成交；信号在数据可得后生成，按交易日历于后续可交易时点执行，不用收盘信息成交在同日收盘。
5. 使用样本外与滚动验证比较“仅质量”“仅相对估值”“质量加绝对价格门槛”，覆盖不同市场环境与参数敏感性。报告净收益、回撤、换手、现金占比、暴露和未成交影响；所有调参留痕，不能从多个测试结果中挑最好的一次作为独立样本外证据。
6. 完成现有 paper 阶段门后才进入模拟盘候选；实盘仍服从独立阶段门、人工确认和审计。

完整策略的最低验收用例：同一公司不同价格产生不同候选判断；股价与价值同时下跌不自动加仓；负/零价值或非有限输入被拒绝；缺失和过期数据不能生成买价；费用后跨越买入阈值；行业模型不适用时阻断；退市/停牌不能因便宜绕过；无候选持现金；报告修订不改变修订前历史决策。首版已覆盖其中计算、研究门禁与假设历史回测，尚未实现多股组合自动配置、可信财报修订回放或独立样本外收益验证。

## 7. 金融依据

- [NYU Stern / Aswath Damodaran：The FCFE Discount Model](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/lectures/fcfe.html)：股权现金流按权益资本成本折现，终值使用下一期 FCFE；FCFE 与实际分红不同，终期预测须与稳定增长假设一致。
- [CFA Institute：Equity Valuation — Applications and Processes](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/equity-valuation-applications-and-processes)：模型应适配业务与数据，区分绝对/相对估值，并披露假设与敏感性。
- [CFA Institute：Margin of Safety — The Lost Art](https://rpc.cfainstitute.org/blogs/enterprising-investor/2015/margin-of-safety-the-lost-art)：安全边际用于应对估计错误，不能保证免于损失。
- [Investor.gov：Bankruptcy for a Public Company](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-84)：普通股在破产中可能失去价值；此处引用股权损失原理，不将美国破产程序作为 A 股交易规则。

以上资料支持估值与风险分析原则；本策略公式、状态、参数约束及落地步骤是项目设计，不是来源机构的收益背书。
