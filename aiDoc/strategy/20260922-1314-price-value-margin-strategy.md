# 价格与价值匹配策略：没有坏股票，只有不合适的价格

> 状态：只读估值研究与单股加现金的假设历史回测已实现；内置价值投资选股策略 `value_investing_margin@v3`（锁定安全边际 30% + 3 年年化 ROE 质地闸门 + 价值陷阱闸门 + 成长路径）已实现并产出研究名单，`@v1`（仅价格闸门）与 `@v2`（价格 + 质地闸门）保留供审计；完整策略执行待实现。本文是本策略定义的唯一真源。
>
> **本报告不提供任何策略有效性证据。** 全部实跑都是单日截面研究快照（`@v3` 最终名单 n=1），未验证收益、未扣幸存者偏差、不含交易成本、不产出权重或订单；假设历史回测的输入是手工假设（`pit_verified=false`），其结果不能作为有效性证明。文中「达标」「通过闸门」只表示规则判定，不表示「已证明会涨」。
>
> 历史模拟使用手工假设与当前可信行情版本，不构成历史时点认证、样本外收益验证或交易资格。
> 定位：在现有多因子研究体系中增加绝对估值与风险补偿视角，作为候选子策略，不替代其他策略和统一风控。

## 1. 投资理念与适用边界

用户理念：“没有坏股票，只有不合适的价格。”

金融实现定义：**在数据可信、价值可估、符合准入且风险可承受的证券范围内，公司质量决定估值、估计误差和风险预算，价格决定投资吸引力。** 优质公司买得过贵也可能回报不佳；经营普通或暂遇困难的公司，在保守价值可验证且价格充分补偿风险时，可以成为研究候选。

不因“优质”无条件买入，不因低质量标签永久排除可估值的普通企业；也不假设每只股票都存在可接受的正买价。股权可能因永久性损失而归零，价格低、跌幅大、低 PE/PB 或历史高价都不能单独证明便宜。

金融专家视角分工：企业分析判断现金流和持续经营能力，估值分析形成情景区间，组合管理决定风险预算，执行风控判断能否成交。任何单一估值分数不能覆盖这些职责。

## 2. 先准入，再定价

沿用项目的数据质量、证券生命周期、ST/退市、停牌、流动性和组合门槛。研究可覆盖观察标的，但交易候选必须满足既有 universe 规则；不以折价覆盖硬门槛。

| 情况 | 研究处理 |
| --- | --- |
| 数据完整、业务可解释、价值可估 | 进入情景估值 |
| 经营走弱但财务可信、仍可可靠估值 | 下修价值、扩大不确定性范围、提高所需折价并压低仓位上限 |
| 财务造假或关键数据无法信赖、剩余股权难以估计 | 阻断买入研究结论，记录原因，不输出伪精确买价 |
| 数据缺失、过期、模型不适用 | 标记“无法评估”，不得当成零风险或低估 |
| 停牌、退市限制、流动性或组合预算不满足 | 标记相应限制；即使估值便宜也不产生可执行买单 |

亏损企业、困境重组不使用普通盈利倍数硬套价格；首版不覆盖不能可靠估值的困境股。恢复资格必须有新的可追溯证据。

## 3. 估值方法与情景

每次估值输出悲观、基准、乐观三种情景的**当期每股权益价值** `V_low <= V_base <= V_high`，并记录估值日期、适用行业、模型、输入、关键假设和有效期。`V_low` 是保守情景估计，不是保证底价；无法形成可信保守价值时不计算买入价。

| 企业类型 | 主要估值视角 | 必须核查 |
| --- | --- | --- |
| 现金流稳定的非金融企业 | FCFF/FCFE 折现，盈利倍数交叉核验 | 维持性资本支出、营运资本、持续盈利能力 |
| 周期企业 | 正常化盈利与现金流、资产价值交叉核验 | 不用景气顶点利润推导“低 PE” |
| 银行、保险、券商 | 各自适用的股利、剩余收益或权益模型 | 资本约束、资产质量和行业专属风险，不套工商企业债务率门槛 |
| 成长或暂时亏损企业 | 可解释的盈利路径、现金消耗及稀释情景 | 未形成可信路径时保持观察，不以远期收入直接承诺价值 |

FCFF 使用与之匹配的 WACC，并从企业价值扣除净债务、少数股东及其他优先权益、加入适用的非经营资产后得到普通股权益价值；FCFE 使用权益资本成本且不重复扣债。最终按同一时点、同一权益口径的稀释股数换算每股价值。

折现率、增长率、预测期、终值、债务与现金调整、股份稀释都需版本化；永续增长模型要求折现率大于长期增长率，币种与名义/实际口径匹配。相对估值只做交叉核验，同行整体高估时不能推出绝对便宜。

## 4. 合适价格的定义

对 `V_low > 0`、当期未复权报价 `P > 0`，定义：

```text
gross_margin = 1 - P / V_low
P_all_in = P + 该笔拟买入数量对应的每股买入费用与滑点
cost_adjusted_margin = 1 - P_all_in / V_low
buy_cost_ceiling = V_low * (1 - required_margin)
买入价格条件：P_all_in <= buy_cost_ceiling
```

`required_margin` 满足 `0 < required_margin < 1`，在训练/研究阶段预先确定并锁定版本，不使用未来收益反推当期参数。估值误差、周期性、治理和流动性风险上升时，重新估值并收紧安全边际及风险预算；不可估值风险不得通过任意提高折价“解决”。

报价、费用、每股价值必须具有一致币种、当期股本与公司行为口径；核心金额和比率使用 Decimal/DECIMAL。最低佣金意味着买入上限依赖拟买数量，不能把 `buy_cost_ceiling` 直接当作可挂单报价。

原研究框架的 `intrinsic_value_gap = V_low / P - 1` 是相对报价的价值差，不等于上述以价值为分母的安全边际。界面和报告必须区分两者。

另评估预设持有期内的净预期总回报：按情景模拟未来卖出价、期间现金分红、费用、税费和资金占用，按现金流时点计算年化回报，与同期限回报门槛比较。当期折现价值不是未来卖出价，不能直接用 `V_base/P-1` 宣称年化收益；当期 DCF 已包含的分红不能再加一次到内在价值。

### 数值示例（纯演示，不是推荐参数）

假设一家公司当期三情景价值为 10/13/16 元，所需安全边际 30%，含买入成本上限为 7 元：

| 含费买入价 | 成本后安全边际 | 研究结论 |
| --- | --- | --- |
| 6.50 元 | 35% | 达到价格条件；其他准入、收益与预算门槛通过后才是候选 |
| 9 元 | 10% | 价格不合适，等待；不因公司好而追价 |
| 5 元，但保守价值已下修至 6 元 | 约 16.67% | 新成本上限仅 4.20 元，不能因跌得更多自动加仓 |
| 任何低价，但关键财务不可信 | 不可计算 | 阻断，不能以便宜覆盖数据风险 |

### 术语表（第 3、4 节与筛选实现的命名对照）

本文有两类「价值」，**不是同一个量**，全文按下列名字严格区分：

| 术语 | 定义 | 出处/用途 |
| --- | --- | --- |
| 情景价值 `V_low / V_base / V_high` | 第 3 节情景估值（DCF/FCFE 路径）的悲观/基准/乐观**当期每股权益价值** | 只读 FCFE 情景研究与假设历史回测 |
| **历史倍数保守锚**（筛选字段名 `V_low`） | `min(EPS_norm × PE_fair, BPS × PB_fair)`，其中 `PE_fair / PB_fair` 是该股**自身历史**正值倍数的 25% 分位 | 筛选内核与研究名单。它回答「相对这只股票自己的历史倍数，便宜到什么程度」，**不是内在价值**，也**不是**第 3 节的情景价值 |
| `P` | 当期未复权报价 | 两者共用 |
| `P_all_in` | `P` + 该笔拟买入数量对应的每股买入费用与滑点 | 第 4 节完整价格条件 |
| `gross_margin = 1 - P / V_low` | **毛**安全边际（不含费用） | 筛选实跑用的就是这个口径 |
| `cost_adjusted_margin = 1 - P_all_in / V_low` | 成本后安全边际 | FCFE 研究与回测路径 |
| `buy_cost_ceiling = V_low × (1 - required_margin)` | 买入成本上限（每股全部成本） | 两者共用 |
| `price_gap = V_low / P - 1` | 折价倍数（以价格为分母） | 排序用，**不是**安全边际 |
| `intrinsic_value_gap` | 原研究框架的 `V_low / P - 1`，与 `price_gap` 同构 | 历史命名，报告须与安全边际区分 |

**筛选实跑的价格条件是毛口径 `P <= buy_cost_ceiling`，不含费用与滑点**；含费条件 `P_all_in <= buy_cost_ceiling`（第 4 节的精确形式）由 FCFE 研究与假设历史回测执行（那里显式计算费用、最低佣金与滑点）。两者在报告里分别标注，不混用。

## 5. 决策与持仓管理

顺序为：可信数据 → 准入 → 情景估值 → 价格与净回报条件 → 风险预算 → 组合/执行风控。

- 未持仓：信息不足时输出“无法评估”；价格未到输出“等待价格”；条件满足输出“买入研究候选”；预算不足输出“组合受限”。可同时保留多个原因。
- 已持仓：买入条件不再满足不等于立即清仓。使用预先记录的持有/退出条件，避免同一阈值附近反复买卖。
- 当期报价达到或高于 `V_base`：触发估值与剩余回报复核，可提出减仓研究建议，不代表必然卖出或确定高估。
- 论点失效、价值永久下修或风险预算超限：优先风险复核，按既有规则提出降仓/退出；无法成交时记录待处理状态，不虚构卖出。
- 超过预设持有期限、复核期限，或出现财报、再融资、重大治理事件：重新估值；过期估值停止支持新增买入，存量持仓进入复核。
- 加仓必须重新满足估值、价格和预算条件，不因价格下跌或浮亏自动摊平。单股、行业、风格、流动性、现金和组合回撤约束优先于估值排序。
- 无合格候选时持有现金；候选不足时保留未分配预算，不为了凑满 Top N 或满仓而降低要求。

完整研究输出至少包含：symbol、估值时点、数据可得时点、情景价值、报价及时间、拟买数量与费用假设、买入成本上限、两种安全边际、持有期及净回报情景、估值假设、风险、失效条件、下一次复核时间、限制原因和数据/模型/参数版本。当前已发布的只读子集见下节，持有期净回报和组合预算仍未评估。

## 6. 项目落地与验收

页面 `/price-value` 按“找待研究的股票 → 评估一只股票 → 查看假设历史表现”三个任务入口组织，默认展示当前有效的优先研究名单（最多 10 只、每行业最多 2 只），可显式查看全部达标池、原走势现金流条件池和基础准入记录。数据阻断或 0 只通过时保持空名单，不自动回退；原始记录由用户主动打开，始终标明未通过/历史状态且不计候选数。PE/PB/ROE 个人条件仅过滤当前视图，不解除后台门槛、不重新排序或补位。0 只通过不代表市场没有低估机会。任务执行失败或尚无报告时不显示原始指标表；完整原因与报告仍可展开或导出。收益记录在独立区域展示，与初筛名单没有收益归因关系。切换入口保留本页尚未提交的表单及已有研究结果，复制手工 FCFE 假设到回测时保留原始可得时间。预填安全边际、折现率、费用等只是待核对的研究示例，不是系统推荐值。

### 已实现：内置价值投资选股策略 `value_investing_margin`（v1 基线 → v3 当前版）

这一节是第 3、4 节中「准入 → 估值 → 价格条件」三段的可执行版本。它把第 4 节要求的 `required_margin` 从「每次请求的入参」变成**登记在案、锁定版本**的策略参数，并在全市场范围上跑出候选名单。

- **策略定义目录**：新增主库表 `strategy.strategy_definition`（见 `aiDoc/modules/schema-plan.md`）。内置策略由 `app/strategies/registry.py::register_all_strategy_definitions` 按 `(name, version)` 幂等注册；`app/repositories/strategy/definition.py` 提供读写。锁定参数落在 `required_margin` 列（`NUMERIC(12,10)`），参数契约落在 `parameters_schema`（JSON），锁定清单落在 `locked_parameters`。`required_margin` 只在版本行里写一次，改值必须发新版本，不能就地改写——这正是第 4 节「预先确定并锁定版本，不使用未来收益反推当期参数」的落地。
- **内核**：`backend/app/strategies/value_investing.py`，纯函数、无 I/O、全部 `Decimal`，同一输入必得同一输出。内核版本 `value_investing_margin_v1`（价格闸门）→ `v2`（加 ROE 质地闸门）→ `v3`（加价值陷阱闸门与成长路径）。**内核版本与策略定义版本独立演进**：内核版本随**行为**变化而变（两套实质不同的判定规则不能共用同一个版本号，否则报告无法回溯到产生它的规则），策略定义版本随**锁定阈值集合**变化而变。
- **数据来源**：估值分布与股本取温层 `research.valuation_history`（`pe_ttm` / `pb_mrq` / `total_shares`）；价格、交易状态与证券主数据取可信层 `market.daily_bar` / `market.security`；盈利、现金流与净资产取**控制面** `fundamental.financial_statement` 完整年报集（温层该表的 Parquet 快照残缺，见附录 B.1；日线与估值历史仍走温层）。**当前价与当前 TTM 盈利结合得到当前隐含 PE**，估值历史只提供「这只股票自己的合理倍数」分布，两者不必同日，报告分别披露 `price_as_of` 与 `valuation_window_end`。
- **目标交易日**：必须是**早于今天（上海时区）**的最近完整交易日。当日 bar 在收盘前是盘中半日快照（实测当日成交额只有前一日的六成），用它比较全日估值会失真。

#### 四层漏斗（`@v1`；`@v2` 在质量层后加一道质地闸门；`@v3` 再加价值陷阱闸门与成长路径）

| 层 | 门槛 |
| --- | --- |
| 准入 | 上市 ≥ 730 自然日、未退市、未停牌、可信未复权收盘价、`special_treatment_status` 为 normal/none、行业标签已核、非金融行业、非强周期行业、20 个交易日日均成交额 ≥ 5000 万元 |
| 质量 | TTM 归母净利 > 0、最近三个完整年度累计归母净利 > 0、三年累计经营现金流/净利 ≥ 0.8、归母净资产 > 0、**三个年报期必须齐备（不齐备即阻断，不得静默按残缺窗口计算）** |
| 价值 | 0 < 当前 PE ≤ 20、0 < 当前 PB ≤ 2、PE/PB 历史正值样本各 ≥ 500 个交易日 |
| 安全边际 | 见下 |
| 质地（`@v2` 新增） | 3 年年化 ROE ≥ 8%（锁定参数）；ROE 未知即阻断，低于阈值即排除（`@v3` 下可由成长路径替代） |
| 价值陷阱（`@v3` 新增） | 4 个年报期的营收/净利连跌年数、资产负债率 3 年变化幅度；命中即排除（已知不合格），趋势窗口不完整即阻断 |

#### 保守锚：双锚取较小者（相对自身历史，不是内在价值）

> 命名纪律（对应第 3 节「相对估值只做交叉核验，同行整体高估时不能推出绝对便宜」）：这里的 `V_low` 在接口字段名上沿用第 4 节记号，但它**不是**第 3 节情景估值意义上的内在价值，本文统一称**历史倍数保守锚**（见术语表）。它是「相对这只股票自身历史倍数的折价锚」；绝对估值（DCF/FCFE）不在筛选内核里，由下文只读 FCFE 情景研究承担。

单一 PE 锚会失真：当一家公司长期盈利低迷时，它的**历史 PE 中位数本身是虚高的**，`EPS × 历史中位 PE` 会算出远离企业实质的「保守锚」。因此同时算两个独立锚，取**较小**者：

```text
V_earnings = EPS_norm × PE_fair        # EPS_norm = TTM 归母净利 / 最新总股本
V_book     = BPS       × PB_fair       # BPS       = 最新归母净资产 / 最新总股本
V_low      = min(V_earnings, V_book)   # 历史倍数保守锚（非内在价值）
```

`PE_fair` / `PB_fair` 取该股自身历史**正值**样本的 25% 分位，用**最近秩下取整**（结果是实际出现过的倍数，不做线性插值，因此不低于插值分位）。亏损期不计入「便宜样本」。

**「取 25% 分位」只保证相对自身历史便宜，不保证绝对便宜。** 分位数保守 ≠ 价值保守：一只历史上长期被高估的股票，其 25% 分位倍数仍可能远高于合理水平；反之长期盈利低迷推高的历史 PE 会污染盈利锚——这正是双锚取较小者的动因，但它只治后者不治前者。当前唯一的绝对水平约束是作用于**当前价格**的 PE ≤ 20 / PB ≤ 2 价闸门，它不约束锚的倍数绝对水平。补「行业或全市场倍数上限」一类约束会改变锁定参数集，属于新版本的事，本版把它列为已知限制而非已解决问题。

> 口径校验（2026-11-09 实测）：供应商 `pe_ttm` 的分母与财报归母 TTM 净利一致，3657 个样本平均偏离 −0.02%、99.8% 在 ±35% 内；净资产锚 `holder_equity_total / total_shares` 与供应商 `pb_mrq` 反推的每股净资产中位数偏离 +1.7%、92% 在 ±35% 内。两套口径自洽，因此内在价值可以在同一套数据里闭合。

#### 价格条件（安全边际 30%，毛口径）

套用第 4 节的公式，参数取登记在案的锁定值 `required_margin = 0.30`。筛选实跑检验的是**毛价格条件**（未含费用与滑点）；含费条件 `P_all_in <= buy_cost_ceiling` 由 FCFE 研究与回测路径执行，两者不混用（见术语表）：

```text
gross_margin       = 1 - P / V_low
buy_cost_ceiling  = V_low × (1 - 0.30)
价格条件          : P <= buy_cost_ceiling
```

边界取闭区间：`P` 恰等于 `buy_cost_ceiling` 时通过。报告同时给出 `V_low`、`buy_cost_ceiling`、`gross_margin` 与相对保守锚的折价 `price_gap`。

#### 为什么要发 v2：只有安全边际会买到「便宜但赚不回资本成本」的生意

### 已实现：内置价值投资选股策略 `value_investing_margin@v3`（价格 + 质地 + 价值陷阱闸门 + 成长路径）

#### 为什么要发 v3：低 PE 最常见的解释不是市场低估，是企业本身在失去价值

`@v2` 的质地闸门（ROE ≥ 8%）挡住了「便宜但赚不回资本成本」的生意，但它是**横截面静态**的：它问「现在的回报率够不够高」，不问「这个回报率是在变好还是变坏」。价值陷阱的典型形态——产品被新技术淘汰、市场份额持续下降、净利润连续多年下滑、负债越来越高、没有新的增长动力——其中大部分在**单个年度的 ROE 上依然体面**，只有在**趋势**上才暴露。

这就是 `@v3` 要补的两件事：**价值陷阱闸门**（排除正在失去价值的生意）与**成长路径**（不因回报率不足而误杀真正的成长企业）。

#### 新闸门一：价值陷阱闸门（4 年年报窗口）

```text
窗口         : 4 个年报期（比质量窗口多 1 期，趋势判定需要 3 次同比变化）
营收连跌年数 : 从最新期向前数连续下滑年数，>= 2 即命中
净利连跌年数 : 同上
负债率 3 年变化 : (最近年报负债率 - 最早年报负债率)，> 0.10 即命中
```

三个信号**任一命中即判为价值陷阱**（`excluded`，已知不合格，不是证据缺失）。语义上的关键区分：

- **单年下滑不算陷阱**。只有连续 2 年下滑才算「持续」，与价值陷阱定义里的「净利润连续多年下滑」逐字对应。连跌计数只统计**实际观测到的**连续同比下滑次数，缺期不臆造连跌（2026-11-10 前缺失中间期会被虚报为连跌 3 年，该缺陷已修复，见附录 B）。
- **负债率上限是排他的**：变化正好等于 0.10 通过，超过即排除。
- **趋势窗口不完整是阻断**：4 期年报凑不齐即判 `blocked`（`trend_window_incomplete`）。在部分窗口上**完整观测到**的趋势事实（如 3 期里连跌 2 年）会如实验记录为证据，但标的状态按阻断（blocked）而非排除处理，且不拿残缺序列外推。

**阈值依据（全市场实测分位数，不是拟合参数；口径与复现脚本见附录 A）**。样本为 2026-11-09 控制面中具备趋势证据的 5,579 只证券（其中 5,556 只 4 期年报齐备），连跌语义为「**实际观测到的**连续同比下滑次数」：

| 信号 | 实测分布 | 锁定阈值 |
|---|---|---|
| 净利连跌 ≥ 2 年 | 1,363 只 | `decline_streak_years = 2` |
| 营收连跌 ≥ 2 年 | 1,305 只 | 同上 |
| 营收与净利**同时**连跌 ≥ 2 年 | 572 只 | 同上 |
| 负债率 3 年上升 > 10pp | 1,098 只（中位 +0.87pp、p75 +7.62pp） | `max_debt_ratio_rise_3y = 0.10` |

> 数字一致性：本表 1,363 / 1,305 / 1,098 与下面「实跑命中统计」及未通过主因表**逐项相同**（同一口径、同一天）。若你手上的旧版报告看到 1,366 / 1,307，那是 2026-11-10 修复连跌计数 SQL 缺陷前的虚高值（详见附录 B 审计记录）；旧表「两者皆跌 838 只」的实测谓词其实是「净利连跌 ≥ 2 年且营收连跌 ≥ 1 年」，与标签不符，已校正为严格同时连跌口径（572）。

阈值 0.10 落在 p75（+7.62pp）之上：`> 10pp` 的尾部群体共 **1,098 只**（含大量地产与建筑），而 `> 5pp` 有 1,799 只——0.10 拦住的是**杠杆结构性上行**这一类趋势性恶化，不是单年波动。

#### 新闸门二：成长路径（价值投资与成长投资并不对立）

成长路径的设计依据是一条价值投资原则：「一家优秀企业如果能够持续增长，即使当前 PE 不是特别低，也可能具有投资价值。关键是当前价格是否合理。」——价值投资与成长投资并不对立。硬性要求 ROE ≥ 8% 会误杀这类企业：高增长期企业的 ROE 常常被扩张投入摊薄。所以 `@v3` 给出一条**并行准入路径**：

```text
成长路径 : 3 年营收 CAGR >= 0.12 且 3 年净利 CAGR >= 0.15
          => 可替代 ROE 质地闸门（其余闸门一个都不少）
```

CAGR 口径为 `power(last/base, 1/3) - 1`，**基数必须为正**否则为 `NULL`（不可为负数开三次方根；负基数或零基数的「增长」不可解释）。

**阈值依据**：

| 指标 | p25 | p50 | p75 | 锁定阈值 |
|---|---:|---:|---:|---:|
| 3 年营收 CAGR | −5.4% | 3.2% | 12.3% | 0.12 |
| 3 年净利 CAGR | −18.3% | −0.6% | 16.4% | 0.15 |

阈值取 p75 附近：全市场净利 CAGR 的**中位数是负的**（−0.6%），说明「持续增长的盈利企业」本身就是小众；把阈值放在 p75 意味着「成长路径」是给少数真正在增长的企业的资格通道，不是放水口。

#### 两条路径的优先级：陷阱闸门优先于成长路径

这是 `@v3` 最重要的语义决定。营收在涨、利润在跌、杠杆在升——这不是成长故事，是**带好标题的陷阱**。所以判定顺序是：

```text
1. 算成长路径是否达标（可能救回 ROE 不足者）
2. 跑价值陷阱闸门 -> 命中即 excluded，成长路径不能翻案
3. 未命中陷阱闸门 -> 走 ROE 路径或成长路径，任一达标即过质地层
```

**成长路径只替代 ROE 闸门，绝不替代价格闸门**：救回质地层的标的仍必须自己满足安全边际 30%，否则照样被价格层拦下。实测里 155 只标的因成长路径被救回质地层，其中只有 4 只同时价格达标，而这 4 只里有 1 只仍被陷阱闸门拦下——最终新增达标 0 只。

#### DCF 在本策略中的定位（不作为闸门）

估值常用指标里 PE、PB、ROE 已全部进闸门；**DCF 不进**。原因与第 3 节一致：DCF 对未来自由现金流和折现率的假设极其敏感，而这两项在本项目里是**手工研究假设**（见「只读 FCFE 情景研究」节），不是可回溯的事实数据。把假设当闸门等于把闸门的确定性交给人。

因此筛选的估值锚继续用**双锚取较小者**（历史倍数分布，不是 DCF）：报告字段名沿用 `V_low`，但语义是**历史倍数保守锚**——「按这只股票自己的历史倍数衡量，便宜到什么程度」，**不等于内在价值**。绝对估值折现由既有的只读 FCFE 情景研究承担；两类「价值」在术语表里有命名对照，接口与报告分开表述。

#### 六维框架的更新

`@v3` 把 `@v2` 节的六维度表扩到七行，新增「是不是价值陷阱」一行（`status=covered`，**是硬闸门**）：

| 维度 | 覆盖 | 硬闸门 | `@v3` 的变化 |
|---|---|---|---|
| 企业靠什么赚钱 | 无数据 | 否 | 不变 |
| 产品或服务有没有竞争力 | 仅代理 | 否 | 不变 |

| **是不是价值陷阱** | **有数据** | **是** | **新增维度**：营收连跌 / 净利连跌 / 负债率上行 |

#### 连接器研究卡：外部数据一律不入闸门

用户授权调用 NeoData 与 westock-mcp 两个连接器。**架构上的硬约束是：外部数据永不进入任何闸门判定。**

理由不是保守，是**不可验证**：连接器返回的券商一致预期、机构评级、研报观点都没有「首次可得时间」，它们本身就是前瞻性预测。把它塞进闸门，PIT 约束就形同虚设；把它塞进报告而不标注，用户就会把预测当成已实现事实。因此：

- 外部观测单独落在**研究库**新表 `strategy.external_observation`（唯一键 `(symbol, source, observation_type, as_of_date)`，`payload` 为 JSON），是**可审计的快照**，不是闸门输入。
- 研究卡 `app/services/value_investing_research_card.py` 把这些观测装配成**研究备忘**，与已实现事实分区呈现：一致预期统一放在 `forward_looking` 块，并固定附带警示语「机构一致预期是前瞻性预测，不是已实现事实，不参与本策略的任何闸门判定。」
- **没有观测就不出卡**：只输出 `symbol` 出现在观测集合里的证券，避免把「看过但没找到」和「没看过」混为一谈。

连接器补上了本项目本地无数据的两个维度：

| 维度 | 本地数据 | 连接器补上 |
|---|---|---|
| 企业靠什么赚钱 | 无数据（`unavailable`） | `company_profile` 主营业务描述 |
| 产品或服务有没有竞争力 | 仅代理（毛利率 + 行业内 ROE 中位） | `company_research` 市场份额：星宇股份 2024 年全球车灯第 7（份额 4.2%）、**中国第 1（11.0%）**；智能车灯**全球第 1（24.5%）、中国第 1（70.2%）** |

**连接器同时独立佐证了陷阱闸门**：金地集团 2026–2028 一致预期 EPS −0.95 / −0.46 / −0.01（持续亏损）、中银国际研报预测其营收 −29% / −31% / −16%；保利发展一致预期营收 −12.66% / −5.11% / −2.9%——与陷阱闸门对这批标的的命中完全一致。这不是把外部数据当证据，而是**两套独立口径互相验证同一个判断**。

#### 口径披露：本地 `roe_3y` 与 NeoData 平均 ROE 不可混用，且确实会翻转个别标的的闸门结论

本地 `roe_3y` 用「3 年累计归母净利 ÷ 3 个年报期末净资产均值 ÷ 3」，分母是**股东权益合计（含少数股东权益）**——比归母口径更严（少数股东权益也参与摊薄）。NeoData 的对比字段是**平均净资产收益率**（`roe_average`，2025 单年、归母权益平均口径）。两者的差异同时来自**窗口**（3 年年化 vs 单年）与**分母**（含少数股东权益 vs 归母权益），量级最高近 4 倍：

| 标的 | 本地 `roe_3y`（闸门判定） | NeoData `roe_average` 2025 | 是否翻转 8% 闸门 |
|---|---:|---:|---|
| 002758.SZ 浙农股份 | 5.70%（剔除） | 11.03% | **翻转**（NeoData 口径会通过） |
| 600686.SH 金龙汽车 | 5.51%（剔除） | 13.92% | **翻转**（NeoData 口径会通过） |
| 000100.SZ TCL科技 | 2.02%（剔除） | 7.88% | 不翻转（两者都 < 8%） |
| 601799.SH 星宇股份 | 13.46%（通过） | 15.05% | 不翻转（两者都 ≥ 8%） |

口径选择会直接改变浙农股份、金龙汽车这类临界标的的结论，所以本策略**固定使用更严的本地口径**并在报告中明示公式。（旧版本此段曾写「TCL 本地 3.40% vs NeoData 7.88% 跨过 8% 闸门线」——两个数字都低于 8%，「跨线」结论不成立；且 3.40% 实为 TCL 的 FY2025 单年「归母净利 ÷ 股东权益合计」（3.39%），不是 `roe_3y`，服务层 `roe_3y` 是 2.02%。该错标已更正，见附录 B。）

另外，**本地算的 3 年 CAGR 与 NeoData 独立算的完全一致**（601799 营收 22.7544% vs 22.7544%、净利 19.9338% vs 19.9338%；000100 净利 158.5546% vs 158.5546%），说明成长与趋势维度的取数口径在两套系统间自洽。

#### `@v3` 的边界

- **锚是相对估值，不是内在价值**：历史倍数保守锚只度量「相对这只股票自身历史便宜到什么程度」。历史上长期被高估的股票，其 25% 分位倍数仍可能绝对偏贵；当前唯一的绝对水平约束是 PE ≤ 20 / PB ≤ 2 价闸门，且只作用于当前价格、不约束锚的倍数水平。这与第 3 节「相对估值不能推出绝对便宜」直接对应——筛选内核不冒充绝对估值，绝对估值归 FCFE 情景研究。
- **DCF 不进闸门**，绝对估值仍由只读 FCFE 情景研究承担（手工假设，不是事实数据）。
- **外部连接器数据永不进闸门**，只进研究卡与 `strategy.external_observation` 快照表。
- **趋势判定依赖 4 个年报期**，年报期不足即阻断（23 只）；财报最早只到 2022 年报，更长的趋势无法构造。
- **阈值是锁定参数不是拟合参数**：换一条标准就是发 `@v4`，不得就地改值，也不得按已实现收益反推。
- **`@v3` 的门槛并未验证收益**：闸门减少的是「已知不合格」，不是「已证明会涨」。本次名单 n=1，不构成统计意义上的证据。

#### 人工治理否决（报告层覆盖，非闸门）

`@v3` 六维框架里「管理层是否诚信、优秀」一直是 `proxy`（近 5 年分红连续性），它**看不见治理丑闻**。为让「高层有问题」这类研究判断可落地，引入**人工治理否决**：研究者基于公开证据对某只**已通过全部量化闸门**的标的做人工否决，在报告层把它移出「优先研究名单」，但**不改变内核的 `qualified` 判定**。

三条铁律（实现 `app/strategies/governance_veto.py`）：

1. **否决永不改闸门**：内核仍报告该股 `qualified`，否决单独记录，两个事实都可见、互不覆盖。
2. **每条否决带证据**：事件、事件公开时间、公开来源，可审计、可争议、可撤销。
3. **否决是当下判断、不是历史事实**：`vetoed_at` 记录的是「人做判断的日期」，不是事件发生日；否决绝不回填历史截面，因此不产生前视偏差。

### 已实现：只读 FCFE 情景研究

- 页面：`/price-value`，菜单“估值研究”；接口：`POST /api/v1/strategy-research/price-value/evaluate`，不写数据库、不生成权重或订单。页面可导出本次研究 JSON；修改参数立即使旧结果失效。
- 输入：证券与报价日期、含时区的估值/假设首次可得/有效期时间、假设版本及依据、普通股稀释股数、三情景逐年 FCFE 总额和明确的 N+1 年终值现金流、权益资本成本、永续增长率、安全边际、拟买股数及显式费用参数。金额单位为人民币元、股数单位为股，不能将万元/万股混入；比例为小数。只支持稳定现金流非金融企业和 1–10 年正 FCFE 预测。
- 计算：`V = (Σ FCFE_t/(1+ke)^t + FCFE_(N+1)/(ke-g)/(1+ke)^N) / diluted_shares`，固定年末折现，不再扣债。每股价值使用 Decimal，以 `ROUND_HALF_UP` 保留 10 位小数后参与价格判断，舍入后非正值拒绝；情景次序错误拒绝，不自动排序。显式终值预测需要包含与增长、再投资及融资结构一致的假设。
- 费用：复用现有 A 股费用内核，所有费用参数由研究请求显式提供，买入不计卖出印花税。`buy_cost_ceiling` 是每股全部买入成本上限；`max_buy_quote` 是在数量、最低佣金和滑点约束下，以 0.01 元价格档位验证得到的最高原始报价，零表示不存在满足条件的正报价。费用仅为研究假设，不代表真实券商收费或订单合法性。
- 行情：只读精确日期的 `market.daily_bar` 未复权报价，要求可信且非可疑、完整来源与更新时间；当前版本晚于估值时点时阻断。本研究保守地在北京时间 16:00 后使用当日日线，并限制报价距估值时点不超过 7 个自然日。这些检查不能替代真正的历史可得时间认证。
- 准入：证券、行业、上市日期、ST 状态缺失，金融行业、非活跃/退市证券、停牌、非正成交额/量、涨停报价、过期或未来假设、论点失效等均阻断，不返回价格指标。当前证券主数据只用于保守筛查，不认证历史 universe。持仓依据失效或报价达到基准价值时提示复核，不自动清仓。
- 返回：三情景价值、两种安全边际、价格条件、费用、行情和证券快照、假设回显、阻断/复核原因、模型/代码版本、输入合同哈希和评估时间。状态为 `blocked / price_condition_met / wait_for_price / review_required`。哈希绑定实际输入而非签署完整输出，不是不可变存储证明。

### 已实现：单股加现金的假设历史回测

- 入口：同一研究页的“假设历史模拟”；`POST /api/v1/strategy-research/price-value/backtests` 创建研究，`GET /api/v1/strategy-research/price-value/backtests/{run_id}` 恢复完整报告。复用现有 `strategy.backtest_run / backtest_trade / backtest_equity / backtest_position`，不新增表或迁移；写入研究记录不改变 paper 账户，不产生真实订单。只读估值接口仍不写数据库。

- 时点：北京时间 16:00 用最新已声明可得版本评价当日收盘价；新版到期不回退到旧版。交易在下一开市日 09:30 使用开盘价执行。若开盘前出现新版或买入依据已过期，撤销旧买入信号，等当日收盘重新评价。手工声明可得时间不代表已核验历史预测；估值在有效期内固定，不自动滚动折现。
- 开仓：仅空仓生成买入信号，100 股整手；开盘按真实数量、最低佣金、税费、滑点、资金预算和前一日成交量容量重算，确认每股全部成本不高于 `V_low*(1-required_margin)` 才成交。剩余预算持现金，不借款、不自动加仓，也不因为价格离开买入区间立即清仓。开盘不使用当日最终成交量或最高/最低价决定成交数量。
- 退出：本模拟为可复现研究，明确选择“收盘达到 `V_base` 或最新已知论点失效 → 次日卖出”的实验政策；它不同于第 5 节一般策略的人工复核建议。已知论点失效不随价格估值有效期结束而解除。退出因跌停或输入中显式不可卖、容量或费用不足未成交时保留意图；部分卖出后继续处理余量。真实停牌日不进入可信日线，当前引擎会按缺持仓行情 fail-closed，不把缺行推断为停牌并重试。普通估值到期停止新买入、已持仓记录复核。期末持仓按末日收盘估值，不虚构平仓；现金不计利息。
- 市场输入：只消费交易日历、证券、未复权可信且非可疑日线及公司行为的 `market` 层。交易日行情须完整，非正/非法 OHLC、缺量额、非停牌却零量或零额、历史 ST/状态未知、缺有效涨跌停价、生命周期/行业不满足均拒绝整段运行。真实停牌日不生成 `market.daily_bar`；可信停牌事件携价尚未接入日频引擎，缺行仍按 `reject_on_open_date_v1` 拒绝整段运行。公司行为区间在事件会计实现前一律拒绝。涨停不买、跌停不卖，滑点后成交价须在当日限价内。前日量只是容量代理，不保证真实开盘深度或成交。
- 留痕：保存完整请求、当前市场输入快照、模型与代码版本、执行/退出/精度政策、合同及数据哈希；独立数据库会话比较运行前后输入，变更时失败。该检查只证明本次计算的输入一致性，不认证历史修订可得时点。内部执行使用 80 位 Decimal 上下文，估值统一舍入至 10 位；费用复用原内核。标准研究表保留其既有定点精度，完整报告 JSON 保留计算输出精度。
- 输出：区间净收益、最大回撤、期末现金与净值、成交、每日权益与持仓、逐日信号/未成交/复核原因和限制说明，可导出 JSON。固定 `research_only=true / pit_verified=false / execution_eligible=false / validation_mode=none`。价格回测不补充净预期收益或组合预算验证；当前主数据会产生幸存者限制，当前修订行情也不能声称无未来信息偏差。

验证覆盖最低佣金与整手、费用后阈值、跳空取消买入、未来/夜间/过期版本、无加仓持有、论点失效与基准退出、显式不可卖输入/涨跌停/容量及退出重试、真实停牌缺行 fail-closed、期末持仓、实际现金守恒、零费用不被默认值覆盖、数据库持久化/查询与失败不写入。

### 已实现：初筛走势与盈利现金流研究诊断

- 版本：报告 `relative_value_research_v7`、逐股 `value_research_diagnostics_v1`；保留原始 `ready_for_review` 数据状态，另列研究条件、来源、缺失/未达标原因、截止日及输入哈希。原条件池按代码查看，默认优先名单按下节版本化规则排序。
- 走势窗口必须是截至目标日的精确 21 个交易日，三所逐日日历完整且一致。`return_20 = close[t]/close[t-20]-1`，`ma20_gap = close[t]/mean(close[t-19:t])-1`。收益大于 0 且均线偏离不小于 0 时为 `improving`，两者都小于 0 为 `weak`，其余为 `mixed`。窗口缺失、停牌、可疑、非有限价格为 `unknown`，不向前滑窗补齐。
- 仅用可信单一来源的完整 qfq 价格；若无直接 qfq，则以可信 `market.daily_bar` 未复权价格乘可信 `market.adjustment_factor`，再除目标日因子归一。同一证券必须有同一 `(source_name, version, release_id)` 的完整 21 日因子；完整组按最新观测时间、来源及版本确定性选择，不跨组拼接、不补常数 1。直接 qfq 只有部分数据或混源时不拼补。逐日输入含值、ID、修订日期和因子信息绑定至哈希。这些当前观测不构成历史首次可得性认证。
- 财务复用 `financial_metrics`：最近三个完整年度固定为财务研究日期 `as_of.year-3` 至 `as_of.year-1`；三年累计净利润必须大于 0，三年经营现金流/利润至少为 1，经营现金流 TTM 必须大于 0。TTM 按最近年报加当年累计减上年同期计算，沿用 4/30、8/31、10/31 报告期新鲜度门槛。`same_evening` 的公告、创建、修订时间的上海日期不得晚于目标日；`current_research_catchup` 使用独立 `financial_as_of` 日期，并将真实带时区的 `analysis_at` 作为公告、采集和修订的可得截止，不能以当天结束时刻代替。价格窗口仍止于 `price_as_of`，双截止不构成历史时点认证。只读 CNY income/cash_flow，缺失/冲突不猜测；金融行业仍需专用模型。明确失败为 `risk`，缺失为 `unknown`，全部支持才为 `supported`。
- 原走势现金流条件池要求原始数据准入和 `improving + supported`，`research_diagnostics.review_eligible` 与 `research_candidate_count` 保持这一含义；默认名单还经过下节精选。可主动查看基础合格行，但不能解除鲜度或数据门槛。读时 `freshness`/`candidate_eligible` 从上海当前日向前逐日核验三所显式日历，直到前一完整开市日为应有行情日，长假和周末不按自然日误判。缺日历为未知，过期/未来/旧版本不进入当前名单；原报告、状态及哈希不改写。
- 以上为明确、可解释的研究偏好，未证明能提高收益、确认止跌或预测上涨；不产生买入信号，不改变 FCFE、回测、组合和交易合同。保留真实逐日报告后，仍需同日基准、成本和独立样本外比较，不能用技术测试替代收益验证。

### 已实现：冻结名单前向观察

### B.1 温层财报历史残缺（v2 轮发现，2026-11-10 前修复）

温层 `fundamental.financial_statement` 的 Parquet 快照（release `20261021-1800`，133,773 行）里 FY2024/FY2025 各约 5,570 只证券，但 FY2022 只有 71 只、FY2023 只有 112 只——导出时这两年已被瘦身出控制面且未恢复。温层并集规则（Parquet 覆盖 `report_date <= parquet_max`，控制面只补更晚行）把控制面后来补回的 FY2022–FY2023 丢弃，导致「三年累计」闸门实际在两年窗口上执行（`annual_periods_incomplete` 命中 5,543/5,586）。修法：服务层改读控制面完整年报集（FY2022–FY2025 各 5,560 只），窗口不足 3 期即 `three_year_window_incomplete` 阻断；未改全局温层并集逻辑（影响回测读路径复现性，属另一次改动）。另补 `report_date <= 目标日` 的 PIT 过滤（此前会取到目标日后才披露的修订版）与财务指标按标的自身已披露最新报告期取值（`financial_indicator` 无披露日，经报告码映射报告期回连财报 `report_date`）。

### B.2 2026-11-10 数字一致性修订记录

本文自命为「唯一真源」，因此内部数字必须全文对得上。本节记录校正过的每一处，供审计：

1. **连跌计数 SQL 落空缺陷**：趋势 CASE 在中间期缺失时，NULL 比较跳过全部 `WHEN` 落入 `ELSE 3`，把缺期样本虚报为「连跌 3 年」。实跑计数 1,366 / 1,307 因此比全市场口径 1,363 / 1,305 虚高 +3 / +2。修为「观测到的连跌数」语义（缺期即止），并把 SQL 抽到 `app/services/value_trap_trend.py` 供服务与测量脚本共享，附语义回归测试。修复后实跑与阈值表逐项相同。
2. **「两者皆跌 838」标签与谓词不符**：838 的真实谓词是「净利连跌 ≥ 2 年且营收连跌 ≥ 1 年」；严格「同时连跌 ≥ 2 年」是 572。阈值表已改正；测量脚本现在同时输出两个口径（572 为主口径，838 一行明确标注为审计行）。
3. **TCL 科技 ROE 口径错标**：旧文「本地算 3.40%」中的 3.40% 实为 FY2025 单年「归母净利 ÷ 股东权益合计」（3.39%），不是服务层 `roe_3y`（2.02%）；且「分母口径不同就跨过了 8% 的闸门线」不成立——3.40% 与 NeoData 7.88% 都低于 8%，不改变 TCL 的判定。真正的跨线标的是浙农股份（本地 5.70% vs NeoData 11.03%）与金龙汽车（5.51% vs 13.92%），口径披露段已改用它们举例。
4. **「> 10pp 群体约 2,000 只」笔误**：真实为 1,098 只（「约 2,000」是 > 5pp 群体 1,799 只的量级）。
5. **展示精度**：名单表的 `V_low` 与买入成本上限均由未舍入值各自舍入，用展示值手算可能差 ±0.01（如 TCL 展示 7.05 × 0.7 = 4.94，未舍入锚 7.0461 × 0.7 = 4.93）。表注已声明。
6. **命名统一**：筛选字段 `V_low` 在文档与产出里统一改称「历史倍数保守锚」，与第 3 节情景估值的 `V_low`（内在价值）区分；生成脚本的表头同步修改。
7. **内核版本一致性**（v3 轮）：`KERNEL_VERSION` 曾停留在 v2 却已加两道闸门，同一版本号两套行为会让报告无法回溯规则——已升 `value_investing_margin_v3` 并把 `kernel_version` 下沉到内核报告字段。
