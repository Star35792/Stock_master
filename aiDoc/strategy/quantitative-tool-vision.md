# 量化工具愿景：自动选股、持仓管控与策略自进化

> 目标：把 Stock Master 从量化投研中台演进为可自动选股、自动管理持仓、并通过持续回测优化策略的量化工具。
> 当前状态：已实现数据湖、因子工厂、单次回测、组合构建、风控与模拟盘执行的 MVP。
> 关键约束：在研究的金融正确性（时点、成本、可交易性、walk-forward）未解决前，不追求全自动实盘。

## 1. 愿景定义

投资理念补充：[价格与价值匹配策略](20260922-1314-price-value-margin-strategy.md)。在数据可信、价值可估、符合准入且风险可承受的范围内，质量决定估值与风险预算，价格决定吸引力。首版只读研究页已提供基于显式预测假设的价值区间、含费买入上限和复核说明；完整策略执行仍待实现。现有 ST/退市、停牌、流动性和组合准入继续有效，价格便宜不能覆盖这些门槛。

### 1.1 自动选股

系统每日收盘后自动：

1. 更新可信行情与因子数据
2. 按 universe 规则过滤可交易证券
3. 运行多因子打分或策略模板
4. 生成目标持仓 / 买入列表
5. 持久化信号并触发后续组合与风控流程

### 1.2 持仓管控

系统自动：

1. 比较当前持仓与目标持仓
2. 触发再平衡
3. 生成订单批次
4. 通过风控检查
5. 在模拟盘或实盘中执行
6. 更新持仓、现金、净值
7. 输出归因与风险报告

### 1.3 策略自进化

系统持续：

1. 维护一个策略池（不同逻辑、不同参数）
2. 通过滚动 walk-forward 评估每个策略
3. 识别当前市场 regime
4. 按稳健性评分动态选择或加权策略
5. 监控上线策略的实盘/模拟盘表现
6. 对衰减或失效策略自动降权/下线

**关键原则：** 自进化不是黑箱 AI，而是「可解释的人工设计 + 系统化的评估、选择与执行」。

## 2. 当前架构的支撑度

| 能力 | 当前状态 | 支撑度 |
|---|---|---|
| 日频数据更新 | `daily_loop` + `factor_pipeline` | 高 |
| 多因子选股 | `MultiFactorStrategy` + `FactorScoreSpec` | 高 |
| 回测验证 | `DailyBacktestService` + 研究合同 | 中 |
| 组合构建 | `PortfolioBuilder` | 中 |
| 事前风控 | `PreTradeRiskEngine` | 中 |
| 模拟盘执行 | `PaperExecutionService` | 高 |
| 策略池管理 | 无 | 低 |
| 滚动 walk-forward | 仅规划，不能执行 | 低 |
| regime 识别 | 无 | 低 |
| 在线学习/强化学习 | 无 | 低 |

## 3. 自动选股的最小闭环

```
每日收盘后
  ├─ daily_loop 更新 market.daily_bar / factor.factor_value
  ├─ 选股服务读取因子并过滤 universe
  │     ├─ 剔除 ST/*ST / 退市 / 停牌 / 新股 / 流动性不足
  │     └─ 保留 allowed_security_types 内证券
  ├─ 运行策略模板生成 target_weights
  ├─ 写入 portfolio_target / strategy_signal 表
  └─ 触发组合构建与风控流程
```

### 3.1 universe 规则示例

- 上市超过 120 个交易日
- 非 ST/*ST/退市整理
- 当日未停牌
- 近 20 日平均成交额 ≥ 1000 万
- 当日有可信未复权 bar

### 3.2 信号持久化

新增表或扩展现有 schema：

- `strategy.signal`：策略信号（signal_date, symbol, target_weight, strategy_name, version）
- `strategy.signal_batch`：信号批次（batch_date, strategy_name, parameters_hash）

信号应先写入，再被组合构建消费，而不是只存在回测结果里。

## 4. 持仓管控的最小闭环

```
收到策略信号
  ├─ 读取当前账户持仓与现金
  ├─ PortfolioBuilder 生成目标组合
  ├─ 生成买卖订单
  ├─ PreTradeRiskEngine 逐单风控
  ├─ 人工/自动确认
  ├─ PaperExecutionService 执行（卖先买后、原子批）
  ├─ 更新持仓、现金、净值
  └─ 输出日终归因与风险报告
```

### 4.1 再平衡触发规则

- **定期再平衡：** 每日 / 每周 / 每月
- **阈值再平衡：** 任一标的目标权重与实际权重偏离超过 X%
- **事件再平衡：** universe 变化、ST/停牌、分红到账

### 4.2 真实成本与可交易性

回测和模拟盘必须统一使用：

- 卖出印花税 0.05%
- 佣金（含最低佣金）
- 过户费、规费
- 涨停不可买入、跌停不可卖出
- 停牌日无行情
- ST/*ST 5% 涨跌停限制

## 5. 策略自进化的分层设计

不要一次性做黑箱 AI。按四层递进：

### 5.1 层级 1：自动化回测工厂

- 对同一策略的不同参数组合批量跑回测
- 按预设标准筛选：夏普 > 1、最大回撤 < 20%、换手率 < 200%
- 输出候选参数集

**风险：** 参数优化本身就是过拟合。必须在样本外和不同 regime 下验证。

### 5.2 层级 2：滚动 walk-forward 选择

- 每月/季度滚动：过去 N 个月训练，未来 M 个月测试
- 记录每个策略/参数集在每个窗口的表现
- 选择「在不同市场状态下都相对稳定」的策略，而不是全样本最优

**风险：** 市场结构变化（如 2021 小市值失效、2024 红利走强）会使历史最优失效。

### 5.3 层级 3：regime-aware 动态权重

- 识别当前市场 regime（牛/熊/震荡、成长/价值、高/低波动）
- 每个 regime 下使用历史表现最好的子策略
- 定期重新评估 regime 并切换

**风险：** regime 识别本身会错，切换成本（换手、滑点）可能吃掉收益。

### 5.4 层级 4：真正的在线学习 / 强化学习

- 根据每日实盘反馈调整策略
- 需要大量数据、严格风险控制、长验证周期

**风险：** 极高。A 股历史短、噪声高、regime 变化快，强化学习很容易过拟合。

**建议：** 两年内不要进入层级 4。先做好层级 1-3。

## 6. 元策略框架设计

```
元策略框架
  ├─ 策略池
  │     ├─ 因子选股 A（价值型）
  │     ├─ 因子选股 B（动量型）
  │     ├─ 因子选股 C（质量型）
  │     ├─ 指数增强 D
  │     └─ 现金 E
  ├─ 评估协议
  │     ├─ 滚动 walk-forward
  │     ├─ 收益、夏普、回撤、换手、基准超额、风格暴露
  │     └─ 稳健性评分（拒绝全样本最优）
  ├─ 选择规则
  │     ├─ 每月初根据过去 12-24 个月滚动结果选择 top-K
  │     └─ 按风险平价或等权分配风险预算
  └─ 风险控制
        ├─ 连续 3 个月跑输基准或回撤超限自动降权/下线
        └─ 新策略必须有 6 个月 paper trading 记录才能进入实盘池
```

## 7. 关键缺口（不只是数据）

### 7.1 数据缺口

- 宏观/信用/政策/盈利预期的真实来源
- 北向、融资、ETF 流、机构持仓
- 公告日/首次可得时间的财务数据
- 历史行业分类、成分股
- 实时行情

### 7.2 方法论缺口

| 缺口 | 说明 |
|---|---|
| 策略 factory / 模板注册机制 | 当前只有因子选股，需要可插拔策略组件 |
| 元策略评估协议 | 如何选择、组合、切换策略 |
| regime 识别 | 没有市场状态分类，谈不上动态适配 |
| 过拟合控制 | 参数搜索、因子挖掘需要 Bonferroni、CSCV、white reality check |
| 衰减监控 | 策略上线后如何发现 alpha 衰减 |
| 实盘执行算法 | TWAP/VWAP/冰山 |
| 多账户资金分配 | 多个策略/账户之间的资金调度 |

### 7.3 工程缺口

- 调度器从「日级数据闭环」扩展到「策略信号闭环」
- 回测和实盘执行统一事件模型
- 策略版本 / 参数版本 / 选择逻辑的完整血缘

## 8. 风险警示

### 8.1 不要迷信「自进化」

量化中最贵的一句话是「我的策略会自动学习」。A 股历史短、噪声高、regime 切换快，自动学习非常容易过拟合。先做成「可解释的人工选择 + 系统化执行」，再逐步增加自动化。

### 8.2 数据质量比数据数量重要

与其急着接更多数据源，不如先把**财务时点、历史行业分类、涨跌停停牌状态**做硬。这三件事错了，再多数据也是毒药。

### 8.3 paper trading 是硬性阶段门

任何新策略、新参数、新因子，必须先跑 6-12 个月 paper trading，且表现符合回测预期，才能进入实盘候选池。没有这个纪律，自进化只会加速亏钱。

## 9. 结论

自动选股和持仓管控在现有架构上可以快速实现；策略自进化需要 2-3 年才能稳妥落地。

**当前最该做的不是加更多数据源，而是：**

1. 把 V4 研究闭环做硬（时点正确、真实成本、walk-forward、风险预算）
2. 基于现有数据先跑一个全自动 paper trading 选股系统
3. 等 paper trading 稳定盈利 6 个月以上，再谈自进化
