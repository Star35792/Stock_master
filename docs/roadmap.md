# Stock Master 路线图

Stock Master 按“可信数据中心优先”的顺序推进。不要先做策略和实盘，先把数据地基做稳。

## 当前阶段：V1 可信日线数据中心

目标：可以把多来源日线数据导入本地 PostgreSQL，经过留痕、清洗、校验、对账和修复后，形成可供回测和策略使用的 `market.daily_bar`。

### V1.1 文档与契约

交付：

- 架构设计。
- 日线字段契约。
- 数据源导入策略。
- 数据质量和人工修复规则。
- 数据库 schema 规划。

完成条件：

- `docs/` 下核心设计文档可指导后续模型和迁移实现。
- README 和 AI 协作文档不再以 AKShare 单源为前提。

### V1.2 Schema 与迁移

交付：

- `raw`、`market`、`system` schema。
- 首批 SQLAlchemy 模型。
- Alembic 初始迁移。

完成条件：

- PostgreSQL 中可以创建首批核心表。
- 唯一键、索引、外键与设计文档一致。

### V1.3 CSV 导入

交付：

- CSV 字段映射。
- 导入批次记录。
- `raw.daily_bar` 写入。
- 基础错误报告。

完成条件：

- 可以导入一只或多只证券的日线 CSV。
- 导入结果可追溯到批次和来源。

### V1.4 基础质量校验

交付：

- 字段完整性校验。
- OHLC 校验。
- 成交量/成交额校验。
- 基础交易日历校验。
- `system.data_quality_issue` 写入。

完成条件：

- 错误数据不会静默进入 trusted market。
- 质量问题可按证券、日期、来源查询。

### V1.5 market 生成

交付：

- raw → market 的标准化流程。
- 基础来源选择。
- `market.daily_bar` upsert。
- 质量状态和来源追踪。

完成条件：

- 回测和查询可以只读 `market.daily_bar`。
- `market.daily_bar` 可追溯到 raw 来源。

### V1.6 多源对账

交付：

- API/AKShare 或其他来源接入为第二来源。
- `market.daily_bar_source_compare`。
- `SOURCE_CONFLICT` 问题生成。

完成条件：

- 同一日期不同来源价格冲突时，不会自动静默覆盖可信数据。

### V1.7 人工修复

交付：

- `market.manual_correction`。
- 手工修复应用流程。
- 问题状态关闭流程。

完成条件：

- 人工修复有审计记录。
- 修复后的 market 数据可用于查询和回测。

### V1.8 最小查询 API

交付：

- 健康检查。
- 证券列表查询。
- 日线数据查询。
- 质量问题查询。

完成条件：

- 外部调用不直接暴露 raw。
- API 查询结果与 `market` 层一致。

## V2 复权、ETF 和指数增强

目标：完善更适合量化研究的行情基础设施。

可能内容：

- 除权除息事件。
- 复权因子。
- ETF 基础信息和日线增强。
- 指数日线。
- 更完整交易日历。
- 停牌状态。

进入条件：

- V1 日线导入、校验、修复闭环稳定。

## V3 因子工厂

目标：把可复用因子计算结果沉淀到数据库。

可能内容：

- 技术因子。
- 成交量价因子。
- 趋势因子。
- ETF 轮动因子。
- 因子定义、因子运行、因子值表。

约束：

- 因子只读取 `market` 可信层。
- 因子计算结果应可重跑、可追溯。

## V4 策略与回测

目标：基于可信行情和因子结果做策略研究。

可能内容：

- 多因子打分。
- ETF 轮动。
- 股票池选股。
- Backtrader 或自研轻量回测。
- 回测绩效指标。

约束：

- 回测输入数据必须来自 `market` 和 `factor`。
- 回测参数和结果必须可复现。

## V5 组合、风控和实盘接口

目标：在充分验证后再考虑实盘。

可能内容：

- 组合持仓。
- 资金曲线。
- 风控规则。
- QMT/MiniQMT 下单接口。
- 订单和成交日志。

约束：

- 实盘必须有人工确认和风控边界。
- 不在数据中心尚未稳定时提前做自动交易。

## V6 可视化平台

目标：提供图表、质量报告、回测结果、组合状态等可视化能力。

可能内容：

- FastAPI 查询接口完善。
- Vue3 前端。
- Plotly 图表。
- 数据质量看板。
- 策略和回测看板。

## 暂缓事项

在 V1 完成前暂缓：

- 分钟线。
- Tick。
- 高频交易。
- 完整财务数据库。
- 自动实盘交易。
- 复杂前端。
- 大规模参数优化。
