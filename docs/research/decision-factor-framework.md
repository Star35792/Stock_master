# 决策因子体系设计

## 1. 结论

当前系统已经具备因子定义、运行、存储、横截面处理、IC/Rank IC、换手率和多因子评分底座，但真正落地的可计算因子主要是价量与风险因子，尚不足以单独支持股票投资决策。

财务报表、财务指标以及涨停、热股、龙虎榜等数据已经能够采集和存储，但“有数据”不等于“已有因子”。目前尚未把它们加工成可按历史时点回放、可检验、可直接进入策略的财务健康、基本面、估值、行业景气和情绪因子。

完整决策体系建议包含六个因子域：财务健康、基本面质量与成长、估值与安全边际、行业景气、市场情绪、价量与风险。因子提供证据，不直接等同于买卖结论；最终结果仍需经过数据门槛、可交易性、组合约束和风险控制。

## 2. 当前能力盘点

| 因子域 | 当前状态 | 已有基础 | 主要缺口 |
| --- | --- | --- | --- |
| 价量与风险 | 已实现 | 动量、波动率、下行波动率、最大回撤、流动性、量能稳定性、换手率 | 可补充反转、Beta、残差波动等 |
| 财务健康 | 仅有数据底座 | 三大财务报表与财务指标采集 | 尚无可回测因子 |
| 基本面质量与成长 | 仅有数据底座 | 财务报表与能力指标 | 尚无盈利质量、成长质量因子 |
| 估值与安全边际 | 未形成因子 | 财务数据与收盘价可作为部分输入 | 缺历史市值、股本、TTM 口径和估值模型 |
| 行业景气 | 未形成因子 | 行业字段、行业指数目录与成分数据 | 缺历史行业关系、行业聚合与景气指标 |
| 市场情绪 | 仅有原始快照 | 涨停池、连板、异动、热股、龙虎榜和游资数据 | 尚未形成防穿越的日频情绪因子 |

## 3. 因子域设计

### 3.1 财务健康

该维度回答“公司会不会因资产负债表或现金流问题发生永久性损失”。首批候选：

| 因子 | 定义 | 方向 |
| --- | --- | --- |
| `debt_to_assets` | 总负债 / 总资产 | 越低越好 |
| `current_ratio` | 流动资产 / 流动负债 | 适中偏高较好 |
| `interest_coverage` | EBIT / 利息费用 | 越高越好 |
| `operating_cash_debt` | 经营现金流 / 有息负债 | 越高越好 |
| `accrual_ratio` | (净利润 - 经营现金流) / 平均总资产 | 越低越好 |

财务结构应在行业内比较。银行、保险、券商必须使用独立口径，不能套用普通工商企业规则。

### 3.2 基本面质量与成长

该维度回答“公司是否具有持续创造利润和现金流的能力”，包括：

- 盈利能力：ROE、ROA、ROIC、毛利率、营业利润率。
- 盈利质量：经营现金流 / 净利润、应收增长与营收增长之差、存货增长与营收增长之差。
- 成长能力：营收、净利润、经营现金流同比及三年复合增长率。
- 稳定与改善：利润率稳定性、ROE 稳定性、连续改善期数。

首批建议实现 `roe_ttm`、`roic_ttm`、`gross_margin_ttm`、`ocf_to_net_income_ttm`、`revenue_growth_yoy`、`net_profit_growth_yoy` 和 `roe_stability_3y`。

增长速度不能孤立使用。高增长同时伴随现金流恶化、应收或存货异常扩张时，应由盈利质量因子抵消得分。

### 3.3 估值与安全边际

“超出市场价值多少”更准确地应拆成两个问题：

1. 相对估值：市场价格相对同行是否便宜。
2. 绝对估值：市场价格相对保守内在价值是否有安全边际。

首批优先实现参数较少、容易回测的相对估值：

| 因子 | 定义 | 说明 |
| --- | --- | --- |
| `earnings_yield` | TTM 净利润 / 总市值 | PE 的倒数，要求盈利为正 |
| `book_to_price` | 净资产 / 总市值 | 金融和重资产行业更有意义 |
| `sales_to_price` | TTM 营收 / 总市值 | 需结合利润率 |
| `fcf_yield` | 自由现金流 / 总市值 | 对资本开支口径敏感 |
| `ev_to_ebitda` | 企业价值 / TTM EBITDA | 便于跨资本结构比较 |
| `industry_valuation_gap` | 个股与行业估值分位之差 | 必须行业中性化 |

后续可实现 `intrinsic_value_gap = conservative_intrinsic_value / market_cap - 1`。内在价值模型需显式记录增长率、折现率、终值和情景假设。只有在压力情景下仍有明显折价时，才宜解释为安全边际。

估值域的共同前置依赖是可信的历史总股本、流通股本、总市值和按公告时点可得的 TTM 财务数据。

### 3.4 行业景气

该维度回答“行业需求、价格、利润和资金关注是否改善”，分为：

- 市场层：行业指数相对强弱、成交额占比变化、行业宽度。
- 基本面层：行业营收增长、利润增长、ROE、毛利率中位数及趋势。
- 高频层：产品价格、产量、库存、开工率和订单等行业特有数据。

首批可实现 `industry_momentum_60`、`industry_breadth_20`、`industry_turnover_share_change_20`、`industry_profit_growth` 和 `industry_roe_trend`。高频指标应保留指标字典、单位、频率和发布日期，不强行统一成含义模糊的通用字段。

### 3.5 市场情绪

情绪因子用于描述风险偏好和拥挤程度，不是简单追逐热门股票：

- 市场级：涨跌停家数、炸板率、连板高度、上涨家数占比、成交额变化。
- 行业级：行业涨停占比、龙虎榜净流入、热度变化、成交拥挤度。
- 个股级：热度排名、龙虎榜净买入占成交额、异动频次、涨停强度。

首批建议实现 `market_sentiment_score`、`limit_up_breadth`、`limit_up_failure_rate`、`hot_rank_change`、`dragon_tiger_net_buy_ratio` 和 `crowding_score`。

极端情绪可能代表短期动量，也可能代表拥挤反转。应保留原始子因子，让策略按持有期判断方向，不永久规定为“越高越好”。

### 3.6 价量与风险

当前已实现：

- 收益与趋势：`ret_1d`、`momentum_5`、`momentum_20`、`momentum_60`、`ma_gap_5`。
- 波动与回撤：`volatility_5`、`volatility_20`、`downside_volatility_20`、`max_drawdown_20`。
- 流动性与量能：`volume_chg_1d`、`turnover_rate`、`liquidity_20`、`volume_stability_20`。

它们适合描述市场行为、交易条件和风险状态，但不能替代公司价值判断。

## 4. 决策结构

不建议把所有因子无差别相加。建议采用“门槛 + 分层评分 + 风险预算”：

1. 数据门槛：财务发布日期、行情和行业归属可信，关键字段缺失则不评分。
2. 排除门槛：退市风险、重大财务异常、不可交易、流动性不足先过滤。
3. 公司评分：财务健康、质量成长、估值形成公司层得分。
4. 环境评分：行业景气与市场情绪调整入场强度和持仓上限。
5. 交易评分：价量、波动和流动性决定时机与执行成本。
6. 组合约束：应用单股、行业、风格、换手和容量约束形成目标权重。

可将以下权重作为研究起点，而非生产结论：

| 维度 | 初始权重 |
| --- | ---: |
| 财务健康 | 15% |
| 基本面质量与成长 | 25% |
| 估值与安全边际 | 25% |
| 行业景气 | 15% |
| 市场情绪 | 5% |
| 价量与风险 | 15% |

权重需通过滚动样本外回测验证，不能根据全样本最优结果反推。

## 5. 时点与防穿越规则

基本面因子最容易泄漏未来信息，必须遵守：

- 使用公告日或首次可得时间，不以报告期结束日作为可交易时间。
- 报告修订保留版本，只在修订公布后使用新值。
- TTM 只由当时已公开的季度数据计算。
- 财务数据至少从公告后下一交易日生效；发布时间未知时采用保守延迟。
- 行业分类和成分按历史时点取值，不用当前分类回填过去。
- 另类数据记录采集时间，收盘后数据只能用于下一交易日信号。
- 缺失值不填零，区分不适用、未披露、采集失败和历史不足。

## 6. 标准化与检验

每个因子进入策略前应完成：

- 在适用股票池内去极值、标准化或排名。
- 财务、估值和部分价量因子做行业中性化；规模敏感因子做市值中性化。
- 记录覆盖率、缺失率、分布、极值和横截面样本数。
- 计算 1/5/20 日 IC、Rank IC、分组收益、单调性和 Top 组换手。
- 检查不同年份、市场状态、行业和市值区间的稳定性。
- 检查因子相关性，避免重复计算同一种风险暴露。
- 在交易成本、涨跌停、停牌和容量约束下做样本外回测。

单日 IC 只是诊断项。基本面因子应重点检验中期窗口，情绪因子重点检验短期窗口。

## 7. 实施顺序

### 阶段 A：时点正确的财务因子底座

- 建立财务字段映射和统一口径。
- 增加公告可得时间、报告版本以及 TTM/同比计算。
- 实现财务健康与质量成长首批因子。
- 为金融行业建立独立适用规则。

### 阶段 B：市值与估值

- 接入历史总股本、流通股本和总市值。
- 实现盈利收益率、账面市值比、自由现金流收益率和行业估值差。
- 完成行业和规模中性化。

### 阶段 C：行业景气

- 建立历史行业分类与成分关系。
- 先实现行业相对强弱、宽度、成交占比和财务聚合趋势。
- 再按重点行业接入价格、库存、产量等高频指标。

### 阶段 D：市场情绪

- 把现有涨停、热股、异动和龙虎榜快照转成可回放的日频指标。
- 明确盘中、收盘后数据的信号生效时间。
- 分别评估短期动量和过热反转效应。

### 阶段 E：决策模型

- 建立因子相关性与冗余诊断。
- 实现分层评分、门槛过滤和环境调权。
- 完成滚动样本外验证，并接入容量、行业预算和风险约束。

推荐顺序为 A -> B -> C -> D -> E。财务时点与历史市值是后续多个因子域的共同依赖，应优先完成。

## 8. 首批实现范围

建议第一批控制在十个核心因子：

1. `debt_to_assets`
2. `interest_coverage`
3. `roe_ttm`
4. `ocf_to_net_income_ttm`
5. `revenue_growth_yoy`
6. `net_profit_growth_yoy`
7. `earnings_yield`
8. `book_to_price`
9. `industry_momentum_60`
10. `market_sentiment_score`

这组因子先覆盖偿债能力、盈利质量、成长、估值、行业环境和市场风险偏好。完成后根据覆盖率和样本外结果扩展，避免一次堆入大量高度相关指标。

## 9. 验收标准

- 每个因子有经济含义、公式、方向、适用行业、输入字段和版本。
- 历史因子值可追溯到当时可得的数据及采集批次。
- 不使用未来公告、未来行业分类或当时尚不可得的信息。
- 因子运行可重跑且幂等，缺失策略明确。
- 报告包含覆盖率、IC/Rank IC、分组收益、换手和稳定性。
- 决策结果可拆解到各维度贡献，组合约束后的调整原因有记录。
- 未通过样本外检验的因子不得默认进入生产评分。
